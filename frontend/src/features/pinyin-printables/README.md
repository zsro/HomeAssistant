# 拼音打印内容

- 入门与拼读两档，五类活动；每页三个活动区，1–6 页。默认第一页为认读、声调、连线，第二页为描写和占余下三分之二页的词语拼写（9 个词）。只选词语拼写时每页 15 个词。选择词语拼写后，额外页数全部用于词语；不选词语时，按顺序轮流填满三个活动区。
- `bank.ts` 保存人工核对的字母、四声、42 条拼读组合及 12 种生活词语。不要根据任意声母和韵母自动拼接音节。
- 入门拼读不包含 `j/q/x + ü` 等需要拼写转换的组合；`nǚ`、`lǜ` 保留两点，生活词 `yú` 按实际拼写收录。首版不出轻声或变调判断题。
- 拼写参考：https://www.moe.gov.cn/jyb_sjzl/ziliao/A19/195802/t19580201_186000.html
- 所有线稿为本项目原创矢量图。配图题按固定词义匹配，不显示中文答案；家人可先帮助孩子辨认图画。

## 常用词语轮换

`words.ts` 收录 18 类、432 个不重复的生活常用词，交错排列类别。PDF 只在左侧显示中文词语，右侧留空白四线格，不打印拼音答案。两档共用该词库，家人可以给尚不识字的孩子读词语。

`progress.ts` 将当前轮次和已使用的词语 ID 保存在当前账号的 localStorage 中。词语文字为稳定 ID，扩充词库时保留旧词即可让新词继续加入未完成的一轮。完整覆盖后再开启下一轮，允许一份练习跨过轮次边界，页内及本批不重复。

`download.ts` 使用 Web Locks 串行化同一账号的多标签页生成。先读取进度、选择词语，再渲染；渲染成功且进度保存成功后发起下载。下载派发异常会回滚进度。重新下载沿用批次中的词语快照，不推进；切换档位、栏目、页数以及生成失败不推进。浏览器无法检测实际纸张打印或用户取消保存，因此以成功发起新批次下载为推进时点。

进度不跨设备/浏览器同步；清除网站数据会重新开始。存储不可用或内容损坏时明确报错，不静默重置；不支持 Web Locks 或非安全来源时提示改用 HTTPS 和新版浏览器。仅取消词语栏目的练习不依赖该存储或锁。

## 字体与 PDF

拼音使用 SIL Andika 7.000 Regular，下载来源：https://software.sil.org/downloads/r/andika/Andika-7.000.zip 。字体原样保留，许可证为 `public/fonts/Andika-OFL.txt`。

中文使用现有 NotoSansSC 可变字体的 400 字重静态子集，内部字体名为 HomeAssistant Pinyin SC，许可证沿用 `public/fonts/OFL.txt`。静态子集既避免 renderer 使用默认 100 细字重，也减少首次下载体积。增加 PDF 中文文案后，安装 `fonttools` 并从仓库根目录执行 `python3 frontend/scripts/build-pinyin-chinese-font.py` 更新子集；渲染测试会检查中文字符覆盖。

浏览器与样张脚本统一通过 `loadPinyinFonts` 加载字体。它先填充 Andika 字形的 Unicode 映射，避免 fontkit 先测量带音调的复合字形后，普通字母被缓存为空映射而导致漏字。不要跳过该加载流程。

`npm --prefix frontend run generate:pinyin-samples` 只生成入门、拼读两份练习 PDF，不提供答案或陪练参考。`npm --prefix frontend run test` 包含全词库循环覆盖、存储异常与并发、页面交互及真实 PDF 排版回归。发布前需将样张渲染为图片检查，并验证单栏 1 页、综合 6 页和长词书写区域。
