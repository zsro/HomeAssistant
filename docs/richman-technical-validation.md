# 大富翁网页技术验证

后续实现以 [分阶段计划与接续记录](richman-roadmap.md) 为准；本文保留 S0 技术验证结果。

## Goal

在已有模块集合里验证原版素材、WebGL 地图、角色动画和道路移动可以组合为可交互页面。本阶段交付本地体验，不是完整对局或线上发布。

## Scope

日本地图、孙小美/阿土伯/钱夫人/沙隆巴斯、手动掷骰、按原始道路移动、岔路选择、拖动缩放、暂停重置、加载重试和资源清理。建筑是验证锚点及前后遮挡的样例布置。

买地收租、电脑策略、股票、声音、云存档、胜负结算不在本阶段。

## Core Gameplay

四位角色都由体验者手动控制，点击角色切换当前操作者。掷骰 1–6 后按节点前进，遇到多个合法出口时等待选择，走完后回到等待掷骰。不重复结算步数；本阶段不计算资产或输赢。

## Screen Structure

模块入口 → 游戏页面。页面包括地图、缩放和跟随控件、骰子操作区、角色列表、旅途记录和岔路按钮。底部可展开运行数据与道路调试工具。

## Interaction Flow

读取资源清单 → 异步创建场景 → 掷骰 → 选择起始方向/岔路 → 播放各段行走 → 完成移动。可以暂停、继续、确认重置或返回模块集合。

## States And Feedback

加载失败给出重试按钮；掷骰、移动时禁用重复操作和角色切换；选择岔路时地图和侧栏同时提示可选出口。暂停冻结移动与动画。重置使用原生模态框，取消恢复之前的暂停状态。后台标签页停止渲染。

## Rules And Edge Cases

路径使用原版有向邻接表，不假设所有道路都双向。默认排除上一节点，无其他出口时允许折返。仅在通过一整段边后扣减步数；岔路选择不消耗步数。重新开始丢弃未完成路段；后台恢复限制单帧推进量，避免角色瞬移。

生成器保留原始帧锚点，人物和建筑按脚下 Y 坐标排序。站立与行走资源编号使用本体文件映射；未验证资料片或其他版本兼容性。

## Data And Technical Notes

- React 负责页面，PixiJS 8 负责画布，纯 TypeScript `Traversal` 负责移动状态。
- 游戏页面使用独立 lazy chunk，访问首页无需加载 PixiJS。
- 当前生成资产约 3.24 MiB，344 个帧，61 个布景对象，110 个节点。
- 每个场景拥有自己的位图和纹理，不共享全局资源加载缓存；退出中止 fetch、销毁画布和纹理、关闭位图、取消 ticker、移除监听器和 ResizeObserver。
- 不引入内存数据库；本阶段没有持久化。完整可玩版再通过迁移增加云端 MySQL 存档。
- 资源转换命令见 `scripts/richman/README.md`；生成物被忽略，不能将此阶段视作已准备好的生产资源分发方案。

2026-09-28 验证结果：

- 前端 lint 和 production build 通过。原有 PDF 打包的 chunk warning 仍存在，与本功能无关。
- 前端 49 个测试全部通过，新增 6 个移动规则测试及 1 个模块导航/鉴权测试，包含 80 次连续移动、岔路、重复命令、暂停、重置和非法骰子输入。
- 隔离 Chrome 浏览器中四个角色均能完成掷骰和移动；三岔路、道路叠层、全图与跟随视角通过。
- 暂停保持位置，原生重置弹窗可用 Escape 取消，确认后清空移动记录。
- 390px 宽度下无横向溢出，地图使用指针事件支持拖动。
- 连续 3 次在移动中返回首页，均观测到 0 个 canvas 和 0 个待执行 RAF 回调；重新进入只有一个画布。
- 模拟清单 HTTP 503 后展示重试，恢复请求后场景正常建立；未登录访问重定向到登录页。
- 浏览器未出现脚本异常；唯一控制台错误来自主动模拟的 HTTP 503。
- 测试机隔离 Chrome 无头环境稳定样本约 57–59 FPS，不代表所有设备的性能保证。首次加载时长受缓存、GPU 和运行模式影响。
- 浏览器场景测试仅在隔离上下文中模拟鉴权 API，没有为实际应用增加登录绕过。
