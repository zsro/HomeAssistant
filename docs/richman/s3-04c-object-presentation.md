## 本批范围与资源证据

本地 `Data.mkf[355..369]` 对应对象类型1～15，每组8个方向帧，共120帧。它们是**方向帧，不是8帧循环动画**。普通神仙、11对象、13礼物、14点数和15衰神按现有公开世界出现/消失，附身对象随人物插值位置移动并换朝向，不增加自主游走、随机数、命令或规则状态。原八首音乐、四音效、十六语音及控制/队列全部保留。

参考版本 `rich4_load_map.asm:586–601` 从 Data396 加载20组，`rich4.asm:1919` 按 type 取指针；本地 EXE 的唯一加载循环改为355，循环仍20次。不能直接沿用参考资源编号：首轮用396解码失败，随后确认本地偏移41并重导出。15组实际帧头、解压哈希、来源包哈希、加载循环机器码和本地偏移表位置见 [资源登记](s3-04c-resources.json)。未在Windows执行原版，不以相同数据认定所有调用栈一致。

`rich4_objects.asm:91–119` 取第一个非零原始邻接边，用邻点→当前格计算方向；不推导游走。Web沿既有已修正方向函数映射当前日本图，保持旧人物方向。附身绘制见 `rich4.asm:1938–2034`：按持有人位置，显示方向加4取模8，偏移用8组二元表；表在本地 EXE 唯一命中。SPR有符号锚点直接用于 `x-anchorX/y-anchorY`，不按图片中心猜测。神仙持有人处于酒店/旅行/监狱/医院时隐藏精灵，退出/无持有人也不遗留旧图。

导出器独立生成 `frontend/public/richman/generated/animation/{manifest.json,objects.webp,contact.png}`，不覆盖旧地图/人物/音频。索引0作为此图集的Web透明色键（原SPR完整转换路径尚未复现）；其余像素保留RGB555颜色。接触表已本地查看，120帧尺寸/边界/透明与不透明像素、图集哈希已检查。原色彩精度、透明转换和实际浏览器混合仍保留差异，不能称原版像素一致。

## 接入、层次和生命周期

- 场景加载可选清单和图集，检查版本/源哈希/120帧边界与8方向偏移；缺失、无效或失败回退现有圆圈/色块/文字。加载取消关闭Bitmap；销毁随场景释放精灵、纹理、Bitmap，无独立RAF/定时器。
- 对象和人物/建筑共用现有按地面y排序的容器；原锚点与偏移保留，文字徽标仍在前层。新图集作为可穿透表现层，不写入旧地产像素命中图，避免错误引用旧图集像素；原精确遮挡/命中排序仍是差异，不在本轮深挖。
- 每帧只投影现有 `SessionSnapshot`：暂停冻结人物插值，恢复继续；移除、替换、期限、换局与G7后按最新世界重建，不回放已发生的附身动画。新局、取消/G7表现flush重置已有步行动画时钟，音频转发不变；网页隐藏复用ticker停止，退出清理。没有保存隐藏G7快照或读取新闻/命运序列。
- 资源外未核实type保持无新图；既有车辆文字/状态显示不变。没有以方向帧冒充爆炸、送神、落地等专属动画。
