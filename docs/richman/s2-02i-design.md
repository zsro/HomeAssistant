# G2 / S2-02 第九批设计

日期：2026-10-04。实施前设计；验收状态另见本组报告，不代表已完成。

## Goal

一次接入停留、冬眠、梦游、陷害、乌龟、机车、汽车七项，合法购买、持有、预览、确认、消耗、到期与回放形成闭环，目标18/43。

## Scope

范围内：独立v8、共享状态时钟、普通玩家的行动限制/监狱位置/释放、梦游步行与恢复、车辆切换及1–3骰；回归原11项。范围外：G3反制与仇恨、旅馆/失踪/保险完整领域、特殊角色、车辆专用图集、精确像素命中；医院共享计时/位置基础保留，实际攻击入院入口留G5。

## Core Gameplay

正常移动赚点 → 三越百货购买 → 掷骰前预览目标/影响 → 确认使用 → 状态按目标行动机会推进 → 恢复。沿用资金、地产、破产、最后存活者获胜；新建/重开清空新卡与车辆。

## Screen Structure

原地图保留；侧栏新增七项库存与可取消预览、交通方式/骰子数选择；角色列表显示状态剩余行动机会。状态跳过显示原因，玩家确认交给下一位；梦游由玩家点击开始，岔路按种子自动选择。

## Interaction Flow

1. 默认新建v8，保留v7及全部旧入口。
2. 七项初始0，点数购买；卡共15格，车辆各持有最多9辆，装备车辆单独保管且不返池。
3. 停留/乌龟可选自己；梦游/陷害只能选附近其他在场玩家；冬眠列出全图合格其他玩家。确认才消费。
4. 车辆装备后机车默认2骰、汽车3骰，可选1至最大骰数；切换返还旧车。遥控仍指定总步数1–6，不按车辆乘倍。
5. 冬眠/监禁跳过行动；停留允许回合前操作但出发时不移动且不重复落点；乌龟每次1步，不抽骰。梦游禁卡/道具/银行/购买升级/特殊落点，仍付可收取的租金。
6. 原子拒绝错误目标、过期/重复命令、暂停提交和非法骰数；取消不消费。

## States And Feedback

普通等待、预览、暂停沿用；受限回合显示“冬眠/监禁/梦游/停留/乌龟”及期限。梦游点击出发，分支自动选路；租金和债务仍由现有确认流程处理（Web操作差异）。监禁角色显示在监狱并于到期回到监狱路格，不返回被捕位置。

## Rules And Edge Cases

按参考原始字节语义：目标行动开始先清0x80，再递减到0时标0x80，当前机会仍生效；自己停留写0x80，他人1；自己乌龟2、他人3，所以均限制3次行动。冬眠5且清梦游；监禁/住院期间冻结冬眠/梦游/乌龟计时，停留继续计时。监禁/住院互斥；梦游暂停车辆，正常到期若库存有车则恢复；冬眠覆盖梦游不会自动重新上车。重复状态按原入口覆盖，监禁按低7位加算。均富集合仍包括监禁/冬眠玩家。无反制卡时不虚构反制。普通地产业主冬眠/梦游/监禁/住院期间不能收租。

## Data And Technical Notes

`japan-tools-candidate-v8`继承v7；用新领域状态记录池、车辆、骰子数与状态字节，纳入新指纹。所有变更通过GameEngine命令，无墙钟计时；暂停/刷新/回放规则与旧架构一致。先冻结实际v7浏览器回放状态/事件哈希。日本监狱/医院路格按原始kind8002/8001匹配84/55；角色建筑坐标来自既有审计，无素材重导。候选选路采用现有种子PRNG，不宣称原rand算法等价。
