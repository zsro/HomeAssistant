# S2-03k 设计约定

## Goal
以v24补日期、交易日、月息、贷款到期/催收；保留v1～v23及已验收37日本命运、36新闻、43物品。

## Scope
固定日本stage0节日表；日期由全员轮转推进；月初无贷款玩家存款结息；贷款90天到期、休市顺延、催收和扣款。原强拍、公司/保险、节日活动与日历驱动的其他物价/神仙系统仍留边界。

## Core Gameplay
新建可选开局日期（默认1998-01-01，为可复现Web起点）；轮转一圈后一天。股票在周日/固定节日休市。银行仍按拒绝/停止放款状态限制；月初结息自动入账，有本金者停息。借款或冒贷设到期日，追加不延期，清偿清日期。

## Screen Structure
日期与银行日历面板显示当前日期/星期/休市原因、所有人的本金和到期日、最近月息与催收/扣款流水；股票面板显示日历休市并禁用交易；银行面板显示到期日。保留暂停、全屏、窄屏。

## Interaction Flow
结束本次行动→跨座位边界推进日历→原有每日候选行情/状态→月初结息→开始下一位→检查贷款催收或自动收款→自身状态计时。结息/扣款不靠弹窗重复确认，不可重放同命令重复收付。催收以可见流水/面板替代原版语音窗口。

## States And Feedback
v24独立calendar对象，持有日期、已过天数、每位到期日、最近结息与催收记录；保存到回放及G7世界快照。贷款到期不足沿现有候选破产退出（不卖股救款、不原强拍），记实付/欠款；胜者正确结束。

## Rules And Edge Cases
只在全员边界推进日历，住宿/旅行/拘留不阻止全局日期；不把自身期限改成全局每日减。银行+59/+60自身行动计时，v24修正住宿时+60也递减。周日+原日本15个固定节日休市，周六可交易；不采用当代法定假日表。月息先于新月当日借款人的到期扣款，有本金则本月无息。到期检查先于设施/状态跳过，银行拒绝也不能逃过催收。全部还清/债务核销清到期日，部分还款不改日。

## Data And Technical Notes
日期算法按源码1998起算和每4年闰年，新建限1998～2099；使用纯日期计算无系统时区。规则指纹继承v23并冻结节日表。日历与月息不额外消耗RNG；休市行情停止但红黑/停牌期限继续原边界减。旧模式无calendar字段，旧随机序列及golden保持。

## Delivery Slices
来源校验→领域/版本/UI实现→边界测试→原图合法日期与银行路线→实际回放和文档接续。未测情形据实单列。
