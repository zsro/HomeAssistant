# S3-02d：主动地产卡策略

新增宿主`estate-v1`，继承`defense-v1`，独立保留basic-v1/tools-v1/rent-v1/defense-v1。世界规则仍`japan-events-candidate-v44 / f9dbb7e9`，不创建v45。三条原图正常速度浏览器、独立核账、最终打包UI与全量回归已通过；计划和领域测试不计浏览器通过。

## 行为与证据

新建对局可选“地产：购地、换地、换屋与拆除（含防御）”。使用UI原名称“购地卡”对应接续卡所说的强买；不另造第五张卡。初始库存仍为零，电脑从实际有限商店货架或既有魔法/神仙等事件获得卡片。商店按购地35、换地25、换屋20、拆除15点顺序补空库存，每种最多补一张；检查供应、货架、点数与15张卡容量，不挤掉已有卡、不花现金。新组补购优先于继承的租金/道具补购，可能花掉本可留给防御的点数，这是本策略的明确取舍。

原G1语义继续使用[第八批原始证据](s2-02h-g1.md)与[物价消费者](s2-03r-indexed-economy.md)，本批只增加宿主选择逻辑，不声称核实原版AI或完整仇恨/难度。

| 卡片 | 既有合法效果 | estate-v1选择 |
| --- | --- | --- |
| 购地/强买03 | 脚下他人普通地，现金付`(动态地价+楼级×建造价)×物价`，原业主银行收款，保留楼级 | 付款后至少1000现金；不以银行/股票补足。资产净增为零时仍可因取得基础租金收益使用 |
| 换地04 | 脚下与附近另一普通地产互换业主，保留楼级，无差价 | 自己资产净增非负，净增为零时基础租金必须改善；允许用自己地换更有价值的无主地，不强行限制原合法范围 |
| 换屋05 | 脚下与附近另一普通地产互换楼级/类型，产权、现金不变 | 同上；只评估普通住宅，排除连锁/特殊类型；两块均非己方且无自身收益时不用 |
| 拆除12 | 附近非己方、有楼级普通地减一级（特殊类型原另有规则） | 只拆其他存活玩家普通住宅，要求其基础租金下降；不拆无主、同盟或己方地 |

估值仅基于当前公开字段：资产=`(动态地价+楼级×建造价)×物价`，基础租金=`rents[level]×物价`。前三卡分数为自己的资产净增扣实际现金支出，再加5倍基础租金增量；拆除分数为对方基础租金减量。系数5是自定义启发式，既不预测未来落点，也不是承诺的回收周期。先按分数、固定卡序和目标ID稳定选择。买卖估值不包含未来日期、持股、挂牌价、公共处置所得、整街/神仙/关系租金修正。

所有候选复用`g1Options`的脚下/440×440附近普通地目标；避开涉及同盟、已退出业主、连锁/特殊类型、查封/涨价中的地产。不主动破坏同盟，不扩张G1目标，不处理大型用地/科研生产；既有科研状态保持。强买和拆除的敌对事件仍由原引擎处理；交换不凭空增添反应窗口。公共处置不救活退出玩家、不代付原债。

仅主动座位idle/beforeRoll、可行动、库存足够时开卡。开卡后按最新库存/产权/楼级/金额/关系重新选择，原目标失效可改选另一合适目标；没有合适目标就取消，不消费。人工将已开卡玩家改成引擎禁止动作的拘留状态时返回无决策，不发送非法取消；这不宣称是正常UI可产生的状态。非当前应答者、反应、付款与其他道具一律委托既有defense-v1链。策略不读取隐藏新闻/命运序列、世界快照或RNG，不克隆引擎模拟未来，不消耗游戏RNG。

## 真实验收

三条实际浏览器导出合计2995命令、730次电脑决策、483次人类决策，24个命名前缀与完整回放已独立核对；四张卡由三条路线合计覆盖，不宣称每局四卡齐全。

| 人数/种子 | 实际命令/电脑决策 | 真实获取与效果 |
| --- | --- | --- |
| 2 / estate-2-0 | 1730 / 353 | 电脑2在turn150商店购换地25点，172把自己的land26换成更有价值的待售land22；176商店购地卡35点，252现金2500买人类1的东京land12，原业主银行增加2500；运行至turn253 |

| 4 / estate-4-0 | 884 / 272 | 电脑4在100经大福神合法获拆除；120把人类1的land21从1降0、产权不变。人类1在49魔法得换屋、85合法开卡后取消，库存/产权/楼级/资金均不变；运行至121 |

四卡各在实际确认窗口检查人类按钮禁用、暂停850ms不推进、恢复以及重开对话框取消后继续电脑动作；同局覆盖遥控骰子与工人等待（两人未触发工人窗口，三/四人覆盖）、全屏/390px、通用重开、替换全人类与待执行退出。三局RAF/canvas归零，errors为空。回放校验器逐条确认电脑决策及当前应答者，核对实际购物费、供应、来源/目标资产与现金→银行、消费/回池，四卡不推进日期或RNG、不改位置/科研，并比对每个关键前缀接续后的全部state/events。

已通过35项领域测试，包括四卡实际引擎结算、物价/动态地价只缩放一次、1000现金边界、只用现金、同盟/查封/类型风险、空耗/负收益过滤、库存/产权/楼级/现金变化后取消、状态门控、旧策略委托与隐藏字段保护、有限补购与容量、非当前反应、人机归属、600ms暂停重算、重开/替换/dispose与元数据。领域夹具不是原图获取证据。

lint/build与最终打包UI已通过（默认全人类/basic-v1、五策略切换、control元数据、重开保留、替换/待执行退出、390px）；全量1930项测试/134文件通过（双worker，506.81秒），含44版本×2～4人共132项兼容矩阵；320份历史fixture逐字节不变，四个旧policy与引擎规则保持。

本批不宣称原版AI一致、所有目标类型/角色/终局，或浏览器中途修改世界字段、电脑自动取消、非当前付款/破产、后台节流/存档恢复、逐座不同policy。连锁/大型用地/科研估值、未来资金风险、其他主动卡片/股票/融资/科研策略后续分组。
