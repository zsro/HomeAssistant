# S2-02 第二批设计：机器工人（当前地块限定版）

## Goal
在普通地产上使用开局获得的机器工人免费建造一级，之后仍可使用遥控骰子或普通掷骰；全流程可回放，旧版本不变。
## Scope
In scope：9 号机器工人的真实开局获取、持有、当前普通地产选择/确认/取消、等级变化、破产清理、旧回放兼容。Out of scope：远处选地、特殊建筑、原版工人动画/语音、商店购买机器工人、其他初始物品。只交付明确标注的当前地块子集，不标为完整还原。
## Core Gameplay
开局每人 1 工人＋1 遥控骰子 → 移动到普通地产 → 下次掷骰前选择当前地产 → 确认消耗工人、免费增加 1 级 → 继续掷骰。取消不消费。普通地产对局胜负/重开保持既有规则。
## Screen Structure
新局模式增加“建造对局（机器工人限定版）”并作为默认；保留首批道具模式。背包增加工人数量、使用按钮和限制提示；选择面板展示地名、道路编号、归属、当前/目标等级与确认/取消。既有地图住宅显示跟随权威等级更新。
## Interaction Flow
检查当前回合、库存与当前地块资格 → 创建选择 token → 明确选择当前地块 → 确认时再次校验 → 消耗与升级原子提交 → 回 idle。保留原有普通掷骰、遥控骰子、银行/地产/商店流程。
## States And Feedback
无工人、非普通地产、满 5 级、非掷骰前均禁用；暂停冻结。选择中普通掷骰被拒绝，取消可返回。工人用完显示 0，商店明确不出售。成功日志显示建造等级，不扣现金或点数。
## Rules And Edge Cases
所有者不限制：可给自己、他人或待售普通地产建造，不改归属。仅当前道路绑定地产、0–4 级可用是 Web 限定范围；原版选择器更广，满级可能空耗，本批不模拟。多道路共享同一地产 ID。工人属于 9 号，不使用前 8 种共享池，消耗/破产不得增加遥控骰子供应。重开恢复初始数量，旧选择无效。
## Data And Technical Notes
新 rulesId `japan-tools-candidate-v2`，保存独立注册表、范围/处理器参数指纹；旧 v1 指纹与初始化完整保留。沿用 effects 草稿和 GameEngine 唯一提交者。仅新增即时 property intent，无日期、RNG、数据库、素材变更。
## Delivery Slices
MVP：初始发放、限定建造、消费/回放。Polish：无效目标、连续点击、暂停/取消/重开、现有遥控骰子组合、针对新功能的浏览器验证。Optional Enhancements：后续先核验原版视窗命中与远处选地，再扩展工具范围，另开规则版本。
