# UI-07：菜单、设置与多尺寸适配

日期：2026-10-19。状态：本地实现与针对性验证完成；未生成正式发布包、未部署。下一阶段为 UI-08 总验收。

## 实现与入口

| 入口 | UI 还原状态 | 业务接入状态 |
| --- | --- | --- |
| 主菜单 START / LOAD / OPTION / EXIT | 使用 Data[1] 背景及四组正常/悬停帧，按本地程序坐标和锚点定位 | 新建对局、设置、确认返回站点可用；LOAD 点击明确提示暂未接入 |
| 开局设置 | 原版角色头像、方形边框与分区；内部排版为 Web 适配 | 当前四名角色、资金、日期、旧模式、种子和支持模式的电脑策略均保留；其他角色标注未接入 |
| 游戏设置 | Data[3] 原版设置面板作为图像参考，旁侧提供可操作控件 | 原有音频、全屏、帮助、开局与电脑配置可用；没有把原图中的空白框伪装成已接入控件 |
| 帮助 | 统一系统窗口，保留现有规则说明 | 可展开阅读、下载回放；明确回放不能恢复当前页面进度 |
| 暂停 / 重开 / 退出 | 原版提示框、YES/NO 与统一系统窗口 | 暂停、继续、确认重开及确认离开复用现有逻辑；嵌套取消恢复进入前的暂停状态 |
| 对局结果 | 原版宝石提示框与 Web 结果账本 | 胜者、破产状态、原有金额明细、新局、下载回放可用；不冒充原版结局动画 |
| 手机布局 | 原图工具栏配常显文字、地图单独缩放、人物和辅助区域重排 | 保留同一地图画布和对局；骰数、地图按钮及主要工具提供至少 44 CSS 像素触屏高度 |

首次载入后打开主菜单并暂停已初始化的默认对局；“继续当前对局”属于 Web 便利入口，不代表读取了存档。主菜单也可从顶部再次打开。原工具栏 LOAD/SAVE 入口继续明确提示业务未接入。

系统页共用一个原生 dialog，通过返回栈处理菜单、设置、帮助、开局、重开和退出。只有首次进入系统页记录暂停状态，嵌套页面不覆盖该状态。确认新局或重开时清理旧窗口 epoch、目标选择和认输确认；取消开局保留原待处理决策。离开路由复用场景销毁逻辑。

- `0x46a9d8` 的四组坐标为 START `(190,380)`、LOAD `(328,380)`、OPTION `(468,378)`、EXIT `(328,450)`；原图按锚点定位。EXIT 热区为触屏扩展，键盘焦点和按压反馈属于 Web 增补。
- 设置加载 Data[3] 的证据为 `0x4114b7–0x4114c9`。本轮使用第 0 帧原图，未宣称其内部原生控件热区已复原。
- 本轮新增 10 张运行图片，累计 **124 张 UI 图片、169 个资源文件**，已登记资源清单；未改写 UI-00 历史审计范围。

桌面沿用 640×480 逻辑布局。可用宽度小于 640 或窗口高度小于 600 时进入紧凑布局；较宽的紧凑横屏使用地图/资料双列，竖屏依次呈现工具栏、地图、骰数与资料。小屏允许纵向滚动，不强行把整个对局缩进单屏。地图保持 440×440 逻辑坐标，GO 拖动按地图平面的实际缩放换算，布局改变不重建地图。
