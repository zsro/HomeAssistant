# G1 五卡设计

## Goal
一次交付购地、换地、换屋、转向、拆除五卡的获取、预览、结算、返池和组合回放，保留全部旧规则。
## Scope
In scope：普通地产、附近玩家、共享卡片商店/15 格容量、独立 v7。Out of scope：大型用地/特殊建筑、拆除道路物件、反制/仇恨/语音；这些已核验分支明确留 G3/G4/G5，不能视为完整原版效果。
## Core Gameplay
攒点购买 → 掷骰前用卡 → 查看脚下源地块与合法附近目标 → 预览产权/楼级/付款或转向 → 确认消耗并返池 → 继续用卡/掷骰；胜负沿用既有破产规则，重开清空卡片。
## Screen Structure
背包/商店增加五项；共用卡片选择面板，显示来源、目标列表与定位、变化预览、现金不足/无目标理由，确认/取消。旅途记录记明效果与目标。
## Interaction Flow
1. 按库存和当前规则开放使用。2. 购地固定脚下他人地产；换地/换屋固定脚下源地块，另选不同普通地块；拆除选择附近非己方有建筑普通地块；转向可选择附近未破产玩家包括自己。3. 确认时引擎重新验证；取消不消费。4. 成功回 idle，继续移动。
## States And Feedback
无卡引导商店；满包/售罄/缺点禁购；无合法目标显示具体原因；选中后显示资金收付和产权/楼级前后；不发生变化的交换仍提示消耗。暂停禁用确认取消，过期/伪造命令不修改状态。窄屏使用原生列表，定位只移动镜头。
## Rules And Edge Cases
购地价=基础价+楼级×建造价（现物价1），现金必须足额，付入原业主存款；不向银行借款。换地只交换 owner，换屋只交换 level（普通建筑类型当前固定），支持无主/同主/同级交换但不能同一块。拆除排除自己地块和0级，降低1级；无主有建筑可选。邻近范围复用固定角色中心锚点候选，不追像素。转向翻转朝向，并在合法邻点中排除旧 previous 后随机选新 previous，无候选写 null；原日本78号第四邻点79禁行按本地字节核验接入v7，旧版本不改。随机源为已有Web种子算法的新范围抽取，非原版rand等价。
## Data And Technical Notes
g1独立卡池/转向显示状态，effect registry继承v6；纯函数生成可选目标和结算预览，UI不提交产权/金额；引擎原子消费、返池与变更。新v7指纹包含价格池、规则、方向限制及效果定义。修改前已冻结实际v6回放/状态事件SHA-256。
## Delivery Slices
1. MVP：五卡共用领域规则和真实获取。2. Polish：预览/定位/暂停、多人组合与浏览器验收、文档计数。3. Optional Enhancements：G3反制、G4建筑类型、G5拆路物件及原版表现；不阻塞已核验普通地产子集。
