# 日本地图缺图核对与修复（2026-10-10）

本轮补齐地图图块与建筑资源，源码与前端发布包已更新，按仓库 Git 同步流程发布。

## 已修复

- 43 个道路图块，共 17 种：命运、新闻、公园、探监/探病、三种小游戏、彩票、50/30/10 点、卡片、银行、商店、魔法屋、普通圆点。此前仅渲染底图及路线；个别新闻图案在底图中已有旧图，现统一叠加原版图块。
- 6 家公司建筑：三越百货、丰田汽车、日产建设、三井生命、SEGA、富士银行。
- 16 个景观全部按记录的资源编号和方向显示，包含此前因空名称漏掉的 4 处帆船。修正东京、富士山、大阪城等错误的名称硬编码映射。
- 日本住宅使用对应日本地图的五级图片；连锁店、公园、大饭店、购物中心、加油站、研究所不再套用住宅。合计 184 个受支持的地产图片帧。
- 广岛大型用地的显示方向采用地图记录的 7，修正原先目录里固定为 0 的显示偏差；轮廓、点击和建筑方向一起修正。

## 数据与来源

[审计清单](map-art-audit.json)记录每个道路图块对应的节点、场景的资源和朝向、建筑图集、源文件哈希及本地 EXE 的资源装载指令字节位置。素材来自用户提供的 `rich4/Game`，未改写原文件。

绘图编号取 MapDat 节点 `+0x22`，不是游戏事件码 `+0x24`。例如 24/26 号小游戏节点的两个字段不同；80/82/84 等节点无落点事件，仍需绘制普通圆点。原版图块位于本地 `map.mkf[12]` 的绘图编号减一帧；场景图像来自记录资源编号加 26，并按记录朝向选帧。

参考固定版本 [rich4 地图装载](https://github.com/mytbk/rich4/blob/ec7d70e693059d1e781d9d1cc2ad7f36d360d39e/asm/rich4_load_map.asm)和[绘图入口](https://github.com/mytbk/rich4/blob/ec7d70e693059d1e781d9d1cc2ad7f36d360d39e/asm/rich4.asm)。该参考版本资源索引与本地游戏不同；不能直接复制参考索引。本轮结合本地 EXE 的 `+26`、住宅 `27 + 地图编号×5`、连锁店 47、大型建筑从 48 起的装载代码和原图联系表核对。没有声称原生 Windows 游戏运行对照。

展示方向放入资源 manifest，不修改经济目录或 MapNode 数组，从而保留旧游戏规则、地图指纹与历史回放。

## 验证

- 5 项 Python 资源映射测试，146 项前端测试（含 133 项历史回放矩阵）通过。
- 独立浏览器渲染：43 个道路图块、22 个场景对象、17 种合法大型设施类型/等级组合；原地图数组逐项相同，关闭调试仍可见；截图无页面异常，销毁后 canvas 清空。设施组合为展示测试夹具，不是通过完整游戏过程建造。
- 现有真实按钮回归：地块和房屋点选、遮挡、建造、暂停、桌面/全屏/390px、回放与退出清理通过。
- lint、TypeScript/Vite 构建、资源哈希与前端发布包校验通过。保留已有的 chunk 大小和 PDF 模块导入提示。
- 可复跑：`python3 -m unittest discover -s scripts/richman -p 'test_map_art.py' -v`；本地 Vite 配合 `scripts/richman/map-art-browser.cjs` 和 `scripts/richman/map-picking-ui-browser.cjs`。

## 仍未接入原版图片的范围

后续状态已更新：车辆/角色状态、路障/地雷/炸弹与骰子在下一批完成。以下为本次地图修复结束时的历史盘点；当前接入状态、暂缓原因与恢复条件以 [接入流程](art-integration-flow.md) 为准。

本轮核对的是地图静态图块与建筑，不代表全部游戏视觉已完整还原。检查当前渲染代码，仍有：

- 车辆和角色状态的专属人物动画：地图人物仍主要使用站立/行走图。
- 路障、炸弹/地雷、机器工人或机器娃娃等部分道具效果：仍有几何标记或路线预览。
- 小游戏内部、部分卡片/道具面板和事件对话：仍为网页界面或简化绘制，未全面映射 `Panel.mkf` / `jump.mkf` 原版图片。
- 原版建筑所有者调色与部分动态效果尚未还原；本轮保留建筑图本身的色边与网页产权边框。

这些是后续美术接入项，不能把“相关逻辑可用”当作“原版图片已经齐全”。
