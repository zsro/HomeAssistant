# S2-02 第五批：路障与机器娃娃

## Goal
增加两项可用物品，形成放置、截停、清路、回收、补购闭环。新增物品优先；原版像素命中精确还原单列待办，不再阻塞 S2-02。
## Scope
独立 v4 候选规则，继承 v3 工人和遥控骰子；旧版本与回放不变。新增 tool:01 机器娃娃和 tool:02 路障。43 项总体范围不缩减，也不以本批两项冒充整阶段完成。
## Core Gameplay
掷骰前放路障；角色进入该格消耗路障并停止剩余移动、正常落点结算；机器娃娃从玩家所在格独立走九格，清除沿途路障，玩家继续掷骰。
## Screen Structure
库存新增两行；商店新增 15 点机器娃娃、30 点路障；路障候选列表显示格号，可定位；地图显示路障标记；娃娃使用前显示九格路线与可清除数量。
## Interaction Flow
开局每人各一件 → 使用 → 选择路格或查看清路路线 → 确认/取消 → 反馈 → 仍可掷骰。商店使用已有点数经济购买，确认提交后刷新决策令牌。
## States And Feedback
暂停禁用消费和购买；取消不消费；非法、过期、重复命令不产生副作用；无障碍路线明确提示仍会消耗机器娃娃。重开清空路障，回放恢复库存、世界与供应。
## Rules And Edge Cases
原始目录供应各 10、上限各 9；开局各 1。路障放置时不返池，截停/清除时返池；娃娃使用立即返池；破产清理背包返池，已放路障保留。普通步行规则内截停；未开放交通工具/免疫/炸弹，不扩写这些交互。
