# S2-03f 设计：剩余十九条新闻统一闭环

## Goal
一次连续任务完成剩余19条新闻的证据核验、可玩实现和真实验收，累计36条；不再逐条等待用户接续。

## Scope
包含4、10、13、14、18～22、26～35及必要的公司持股排序、账面损益、停牌、贷款限制和基本借还款。保留43物品、v1～v18所有规则与实际回放。日期/定期结息、原破产强拍、完整商业建筑经营及像素遮挡不在本批。

## Core Gameplay
原图合法行走、建设、持股建立条件；到新闻格依36项固定序列选择，显示实际变化。经营者拘留先显示待处理，确认进入免罪/嫁祸处理，再展示最终结果。其他新闻一次结算，确认仅推进。

## Screen Structure
沿用新闻明细、暂停/重开/全屏；股票面板展示全市/单股停牌、公司经营者和两本账；银行提供基础借款/还款，显示欠款、可借上限与停止放款期限。设置提供v19及所有旧版。

## Interaction Flow
1. 买股后按数量排序取得公司经营权；已有建造、研究、交通功能建立灾害对象。
2. 新闻变更地价/建筑/现金/税款/公司损益/行情或启动经营者反应。
3. 停牌期间拒绝主动交易；贷款限制期间拒绝借款但允许还款；期限按候选行动/轮次推进。
4. 回放逐命令复现，包括反应窗口、公司排序、税破产和时光机快照。

## States And Feedback
区分待反应与已结算，不能重复确认；展示停牌剩余边界、贷款余量和债务。无对象按既有序列跳过；灾害可能无实际建筑变化仍合法。公司亏损可为负数，与个人余额分开显示。

## Rules And Edge Cases
股票大户按股数而非市值；证交税按总市值5%且无卖股自救；降地价截断到16位。范围灾害沿用投影方框候选，不冒充原像素命中。经营者按持股降序、已有同量者优先；公司账本按有符号32位。停牌文本10但函数15，以代码值登记差异。停止放款15，单股15，全市10；每轮/自身行动代替原日期。公司加倍同时累计账本加新值，保留原公式。新闻29免罪优先、嫁祸可选，无复仇/敌意，实际目标监禁5。

## Data And Technical Notes
新增v19完整新闻规则与指纹；新增字段全部置于NewsState.business，旧版不出现。贷款上限采用源码资产减现有贷款；借款进银行，还款先银行后现金；不实现利息/到期催收。公司对应日本地图6条52字节记录及其关联股票，非虚构12家公司。时光机已有news与市场快照一起恢复。

## Delivery Slices
1. 固定来源与领域实现：灾害/资产、市场/贷款、公司/反应，作为同一交付。
2. 全量回归与原图合法路线正常速度浏览器，真实回放与截图；未覆盖边界单列。
3. 更新规则、36项进度、真实验收数和剩余S2-03范围。
