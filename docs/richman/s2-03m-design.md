# S2-03m 公司日期分红设计

## Goal
完成已有公司新闻账本 → 合法股票持仓 → 每月15日结算 → 可见账单/破产清理/回放的 v26 闭环。
## Scope
日本六家上市公司；保留 v1～v25，不补猜测的公司服务或保险营业额。
## Core Gameplay
买入公司股票，已有新闻30/31/32/33/34/35改变公司当期/累计账面。日期进入15日，所有未退出持股人按实际持股比例承担公司正负收益。
## Screen Structure
新增公司账本与分红面板，展示六家公司当期/累计、实际参与股份、最近逐公司分配和个人银行/现金变动。
## Interaction Flow
沿用股票买卖与新闻确认；日界自动结算，无额外确认，无额外随机数。日期顺序：行情→分红→彩票→下一玩家贷款与状态时钟。
## States And Feedback
无持股结转；有持股清本期而保留累计；零收益仍生成账单。银行不足扣现金，仍不足退出并释放彩票/库存等；日志显示总分红和退出。
## Rules And Edge Cases
分母仅存活玩家持股之和；每公司先float32比例，再乘有符号账面并向零取整，逐公司结果按int32累计。全公司计算完才逐玩家入银行；负数不足不卖股票抵债，沿用明确Web退出约定。参与不受住宿/监禁/休市/停贷限制。不平摊余数，不动公共资金。破产后重选下一存活玩家，最后一人获胜；全员同时无法承担时无赢家结束（Web约定）。
