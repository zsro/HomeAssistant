## 实现与使用

默认新场景为“道具组合对局”，规则 `japan-tools-candidate-v4`、指纹 `dde79d34`。新局菜单保留 v1/v2/v3 和更早模式。

- 路障：每人初始 1 个；掷骰前在固定角色周边的空路格选择、定位、确认放置。地图显示红黄标记，放置后可以掷骰。任何步行玩家进入该格，路障消失，剩余步数归零，正常进行该格银行/地产/点数/商店结算。
- 机器娃娃：每人初始 1 个；显示起点和完整九格路线、将清除的路障数量，确认后独立清路，玩家位置、资金、点数、骰子 RNG 不变；仍可继续用工人、骰子。无障碍时仍可消费，界面明确提醒。
- 三越百货：新增机器娃娃 15 点、路障 30 点，各有限供应 10、单人持有上限 9。路障占用世界供应，移除时返池；娃娃使用时返池。破产背包返池，世界路障保留；沿用既有“无库存折现收入”的候选清算。
- UI 的预览只是选择，GameEngine 重新验证目标并提交。暂停、过期令牌、重复命令、错误操作者、非法目标均不得改变状态。回放覆盖背包、供应、地图物件及效果事件。

## 显式 Web 差异

1. 路障目标复用已经验证的固定方向 0/角色道路中心/[0,440)² 锚点投影，加空路格过滤；不依赖相机、不模拟原版像素遮挡、不禁止与人物共格。与 v3 工人选择差异一同保留标注。
2. 机器娃娃岔路采用**排除前一格后选最小编号、死路折返**，不抽 RNG；这是可预览、可重放的 Web 候选策略，尚未证明等同原版 +14/方向/随机岔路选择。预览与引擎执行共用同一个函数。
3. 娃娃九格原子结算，没有原版行走动画、音效；路障暂用 Web 图形标记。不是资源缺失错误，不重扫/重新导出全部素材。
4. 原版像素命中、复杂交通/免疫/炸弹/神仙等关联不混入本批；不能据此宣称两件道具全部原版交互完成。
