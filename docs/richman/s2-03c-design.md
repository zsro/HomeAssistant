# S2-03c 新闻地产组设计

## Goal

在新闻格结算有来源支持的地产变化与土地数量奖励，玩家能查看目标、产权、建筑和资金变化后继续。

## Scope

接入新闻5随机已建地块清产权/建筑、15随机普通已建地块降级、8土地最多者现金奖励、9土地最少者现金补助；新v16继承v15四新闻、v14得卡和43物品。其余新闻、原图像/音效、完整日期/结息与贷款不在本批。

## Core Gameplay

正常移动或自传送停在新闻格→按既有36序列检查条件→抽取合法地块或按数量选玩家→原子结算→显示前后明细→继续回合。地产变化影响后续购买、租金与科研，新闻本身不消耗物品。

## Screen Structure

保留地图、资金、库存与股票区；复用新闻面板显示地块名/编号、类型/等级、产权变化与研究取消，或地块数和现金奖励。默认v16，旧v15及所有旧模式可单独选择。

## Interaction Flow

条件不满足跳到下一候选；新闻5/15从普通地产编号升序后大型用地编号升序的合法集合抽取一块，不按附近/业主筛选。结算后交易锁定，确认仅继续；暂停禁确认，重开沿用确认框。

## States And Feedback

明示已结算；无合法建筑时不抽目标随机数，序列继续推进。目标、金额和科研取消均记日志；重复/过期确认不能重做。窄屏沿用可滚动明细。

## Rules And Edge Cases

5包含无主建筑、大型建筑，清归属/等级/类型/研究；价格状态保留，无赔偿/费用/敌对反应；大型建筑触发所有未退出住宿者标记128，下一自身行动离店。15只选普通已建地块，住宅减一级、连锁店归零且重置类型，保留产权；原条件包含大型建筑但函数只选普通地产，Web显式收窄条件避免空集合。8/9计普通+大型产权数，包含空地和零产权玩家；退出者排除、拘留者保留，平手取最早席位。奖励10000/5000现金，银行不变；物价固定1。时光机按已有领域快照恢复，RNG不回退。

## Data And Technical Notes

v16独立指纹，v15序列与日志结构不变。新日志保存目标候选、建筑前后和计数；源函数固定提交校验。复用既有地产与科研状态，无数据库/素材重导。

## Delivery Slices

1. MVP：四新闻、独立版本、领域边界与合法原地图浏览器组合/回放。
2. Polish：原版运行、图像与音效对照。
3. Optional Enhancements：继续其余地产新闻及日期基础，经核验再接入。
