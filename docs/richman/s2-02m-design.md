# G6 神仙与股票设计（v12）

## Goal
整组交付送神符、请神符、红卡、黑卡及其可操作的领域基础，累计40/43已实现、18/43历史验收。用户要求全部43项完成后统一自动测试，本轮仅源码审阅与静态类型检查。

## Scope
独立g6/v12继承v11。四卡商店补购/有限池/15格库存/抢夺/破产回收；12类可附身神仙、停留道路遭遇（经过不附身）、附近最近召请、替换与期限；日本12支股票、银行结算交易、限额/持仓/成本/行情历史、红黑状态、租金最终付款人的必要清仓及资产汇总。

## Core Gameplay
点数格获点→商店购卡→回合开始选择/预览/取消/确认。地图可遇神仙，也可请神；不利附身或携带炸弹时送神。玩家主动用存款买卖股票，再用红黑卡改变市场；股票不足以救济租金时才进入既有破产流程。

## Screen Structure
沿用卡片选择面板；新增可折叠股票表与交易确认、神仙位置/效果/期限列表，地图标记游离神仙。结算面板计入股票估值；小屏滚动表格，不改变全屏与原角色绘制。

## Interaction Flow
股票选择→填写正整数股数→展示价格/成交总额/交易后余额→明确确认；卡片仅掷骰前使用，股票仅可行动的idle/turnEnd交易。移动/暂停/反应/拍卖/结算/结束均禁止交易。每个命令仍受game/revision/player校验。

## States And Feedback
所有新状态进入GameState/事件/回放；市场不依赖墙钟，暂停不计时。附身替换移除旧神，不叠加；送神无有效目标不消费；请神只有最近合法一项候选；红黑卡展示同一基准价、当前价与结果。交易失败不改变账户，成功清空输入防止重复点击。

## Rules And Edge Cases
核验来源为固定参考提交ec7d70e693059d1e781d9d1cc2ad7f36d360d39e的四卡、gods、stocks、player_core_actions与原始表。语义B级，未做Windows运行对照。精确规则登记在本组报告。明确Web约定：神仙种子布点/定期补充、投影锚点范围、种子替代转盘、缺失现金扣款截断不新增神仙债务、空大型天使默认饭店、每轮代替交易日、种子行情不声称原版随机轨迹、股票应急清算按股票顺序最少股数。公司控股/保险/营业日/神仙运气参数/动画非本轮完成范围。
