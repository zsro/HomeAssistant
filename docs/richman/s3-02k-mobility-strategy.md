# S3-02k：主动移动与车辆策略

新增宿主 `mobility-v1`，继承 `roads-v1` 与十个更早策略。世界规则保持 `japan-events-candidate-v44 / f9dbb7e9`。五条原图正常速度浏览器、69个命名前缀及完整回放通过；2263项测试/148文件分两次通过，十二策略打包UI通过。

## 策略与规则边界

| 项目 | 策略选择 | 原效果与边界 |
| --- | --- | --- |
| 转向卡06 | 只调整自身；逐一评估原合法候选previous，最差结果仍比当前最佳骰数路线分值高25才用 | 面向加4模8、确认时由引擎抽候选previous，不立刻移动；策略不预读这次随机结果。保留对他人使用的人工能力 |
| 机车05/汽车06 | 仅向更高最大骰数升级，避免同回合换来换去；确认重算 | 80/150点合法货架购买，默认2/3骰；装备耗1件、旧车入包、装备不返池；机车/汽车都可选1骰 |
| 骰数/岔路 | 公开1～3骰分布的加权路线分值，平分少骰优先；最多18格，按实际剩余步数选岔路 | 不抽游戏RNG、不假装知道下一骰；到岔路后已知实际总步数，允许择路。路障截停；地雷/炸弹地面物仅落点危险，携带倒数在本次可走到归零时降分 |
| 工程车12 | 合法装备、附近敌方有楼且当前六步评分改善才用；所有六步友方可达位置有盟友楼/科研则拒绝 | 含当次7自身行动、一骰；原车/骰数保存，车入包；落点结算全部完成后的endTurn拆非己方楼，随后减工程车期限；不是拆楼免租 |
| 工程车获取 | 只在当前已有自有四级及以上科研楼，合法空闲项目中补产1辆，避免库存/装备/在研重复 | 免费等待5次自身行动；不进商店，不新增初始赠品，不增加建站、追踪升级或高级科研投资策略 |

路线评分为自定义启发式，不是原AI。可负担普通地产待售40、自有且楼级低于5时30、5级10、点数地点20（自有地是固定安全落点分，连锁类型的实际上限仍由旧购建决策判断，不保证本次可升级）；敌方地块以当前普通街区/连锁涨价租金、设施收费上界及1000元余量降分，工程车另加敌方楼级收益。工程车对盟友有楼/科研落点极低分，待售建筑拆除降分，自己产权不拆。资金计算不假设未来卖股、免费/嫁祸、保险收入或退出后公共拍卖会救活玩家；不是完整神仙/公司/持仓间接收益预测。

随机新闻、命运、神仙未来位置、下一骰、G7快照均不参与评分。不克隆引擎模拟，不读取隐藏序列。转向卡实际确认仍按v44正常推进游戏RNG；“策略不用RNG”不能误写成“转向效果不抽随机数”。暂停、取消、重开和退出沿Session既有600ms等待失效机制；非当前反应/竞价/实际付款委托旧策略链。

车辆装备按骰数灵活性固定加分，不是本次现金净收益最优解；暂不主动下车/降档，也不在装备前优化未来加油费、保险或车辆损毁损失。装备后选骰与选路会按当前车辆收费上界避险。工程车当前六步避险不保证未来七次行动安全。关系/建筑/状态可在后续变化；道路路障与携带炸弹仍可改变真实到达。无安全路径时只能在现有合法路线中降损，不能阻止引擎原有拆盟友楼、地雷/飞弹损毁车辆。原长期陷阱风险保留。

## 依据与差异

重读前批G1转向、G2机车/汽车与G5工程车来源；沿本地既有合法目标、车辆装备/库存、生产、梦游与工程车计时、落点收尾链核验。车辆动画仍为既有表现；不增加原版AI、像素范围或Windows运行一致性声明。

工程车梦游暂停计时；自然梦游结束恢复，异常清除梦游不自动恢复工程车。工程车到期仅在原车库存尚有时恢复原车/骰数；原车已失去则不能凭空补回。地雷/爆炸、拘留、住宿、停止/乌龟等按原状态规则执行，新策略不会用装备绕过限制。
