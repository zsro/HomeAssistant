# S2-03l 彩票与日期开奖设计

## Goal
以v25接入日本彩票地点和每月15日开奖，保留v24日期/银行与全部旧规则、回放。

## Scope
本批包含28/88彩票落点、1～36唯一号码、每次买一张、现金费用、共享公共资金、中奖/无人中奖/无票、破产清票和回放。原版开奖动画/语音随机数、AI购彩、完整公司分红、其他节日与原强拍不在本批。

## Core Gameplay
普通落在彩票格→查看36号及归属→支付现金1000买一个空号或离开→每月15日自动开奖→获奖人领取公共资金到现金，清空全部号码；无人中奖保留票与资金。

## Screen Structure
新增彩票与奖池面板，常驻显示公共资金、各玩家持票、最近开奖。购彩时显示号码下拉、费用/现金与购买和离开按钮；无可选号或现金不足提供原因。沿用日期面板、日志、全屏及窄屏布局。

## Interaction Flow
每次落点只允许一张，成功后结束当前行动；离开不消费。经过与梦游不弹购彩。全员边界更新到15日，行情之后、下一位自身行动之前自动开奖；不增加可重复领奖按钮。未售完并不妨碍开奖，开奖日休市不影响开奖。

## States And Feedback
旧模式没有彩票字段/面板；v25持36个owner槽与最近开奖记录，使用现有news.publicFund唯一账本。无人持票时不抽随机数；无人中奖明确显示“票与奖池结转”；中奖显示号码、获奖者和现金入账金额。

## Rules And Edge Cases
人类现金至少1000；不使用存款，不按物价调整，不触发免费/嫁祸。任一玩家持票超过10张时只从已售号码按序建候选，否则1～36全部候选。破产只清该人的票，不退款，号码重新可买；其他人和奖池保留。暂停、重复/旧决策、错误玩家、售出号码与非整数拒绝且无副作用。时光机按现有世界快照一起恢复票、奖池和日历，为Web集成约定。

## Data And Technical Notes
源码为固定参考仓库的跨版本B证据；新语义v25。复用种子g6Draw单次范围抽取，不复刻原CRT、GetTickCount及动画随机消耗。原15日公司分红调用在彩票前，但完整分红未接，不据此加入猜测收益。日历、公共资金、RNG边界纳入规则指纹与实际回放。

## Delivery Slices
1. MVP：源码/初始化/破产链核验、领域和界面接入。
2. Polish：领域边界、原图合法购票/无人中奖结转/中奖、2–4人浏览器与独立回放。
3. Optional Enhancements：后续另版核验原动画、完整分红和其他地点；本批结果与下一接续落盘。
