# S3-01a：基础电脑对手

规则保持 `japan-events-candidate-v44 / f9dbb7e9`。新增的是宿主策略 `basic-v1`，通过已有 `GameEngine.dispatch` 提交普通命令；不修改付款、移动、物品、日期、股票或世界恢复规则。S2-03/04/05候选收口及43物品、36新闻、日本37命运历史基线保持。

## 交付范围和入口

新建对局的默认v44模式增加逐角色“人类/电脑（基础）”选择，默认仍全人类。支持2～4座、混合控制和全电脑观战；旧模式继续全人类。角色ID映射座位，不依赖连续角色索引。中途托管、难度、主动用卡、股票策略和研究生产不在本批。

电脑面板显示实际应答者、当前理由、上次决策与暂停/错误状态。电脑应答时禁用人类操作区，且Session命令入口再次校验，不能靠地图/快捷输入越过UI禁用。全局暂停、新局、重开、退出可用；错误停止后允许显式重试。

## 命令和生命周期盘点

| 场景 | 应答者与策略 |
| --- | --- |
| idle / turnEnd | 当前行动者，roll / endTurn |
| roll / segment | 原渲染调度完成动画，电脑不抢发animationDone |
| branch | 公共可见的一跳地产评分；可负担待售4、自有可升3、自有已满2、非地产1、不可负担0、他人地产−2，同分小路格优先 |
| property | actual payer；租金确认；购地/升级报价为0或付款后现金至少1000才接受；大型初建选列表首类型 |
| bank | 拒绝往来直接离开；否则现金调到min(5000,现金+存款)，再离开。不借贷、不提前清股 |
| debt / auction / reaction | payerId / responderId；确认既有清偿退出 / 放弃竞价 / 不用可选反应卡。真正清股、公共处置、外层回调仍由原规则处理 |
| shop / lottery / facility | 离店、不购彩、不付费探访 |
| news / fortune | 确认账单；逐位取卡选可选列表首张，无卡则放弃 |
| company / insurance / subscription | 确认营业、保险正常抽取、跳过认股 |
| construction | 第一处自有可升且费用后现金≥1000的候选，类型选首项；否则取消，照原规则仍可能收取消费 |
| magic | 抽目标→选择得一张卡片→继续；嵌套建造按实际responder选公园 |
| minigame | 正常quit，按实际得分确认返回；不伪造奖励或模拟完成原玩法 |
| effect | 取消未完成选择；本策略不主动进入物品选择 |
| paused / finished | 不自动行动 |

费用判断直接使用待决策报价，选路基础价格只是启发式，不再次计算实际账单。策略只读公开状态，不窥探新闻/命运未来序列、不调用游戏RNG。原版托管设置、卡片RNG/仇恨策略与本策略不等同，缓存来源定位见[sources](s3-01a-sources.json)；没有本轮Windows实机对照。

调度复用画面tick，每项决策等待600ms，每帧最多累积50ms，按gameId/revision失效。提交时重新读当前合法状态，使用新命令ID和当前版本号。暂停取消等待；恢复重新等待；新局/重开替换引擎并清空等待/错误；场景destroy调用dispose，后续tick/命令不再运行。没有独立后台AI定时器。拒绝命令或无可处理决策会停止并显示原因，不自动重试死循环。

`GameConfig`、`GameState`及旧引擎回放不增加控制字段。仅电脑局导出顶层`control:{version:1,policy:'basic-v1',computerIds:[角色ID]}`；全人类导出保持旧形状。引擎重放依赖实际命令，不重新运行策略或消耗RNG。该元数据不是存档载入/恢复AI计时器功能。

## 验收口径

本批1786测试/124文件、132版本人数矩阵、lint/build最终干净通过；新增10领域＋3实际回放，280历史fixture逐字节不变。原图共1454实际命令，其中257条电脑决策；每条路线7类关键前缀及完整状态/事件一致。具体命令与结果见[真实结果](s3-01a-results.json)。领域测试允许显式旧回放状态快照；浏览器仅鉴权fixture，真实原图新局、正常动画、人类命令点击、电脑座位自行行动，不注入游戏状态。

- 领域：非连续角色、纯策略不改状态/RNG、后台帧钳制、暂停恢复、新局/重开/dispose、非法配置原子保留、银行拒绝、错误停机/重试；历史反应/拍卖/债务/魔法建造实际应答者和相反的人类应答；2～4人长局及完整回放。
- 开发页：2～4人混合座位，角色2（及四人角色4）为电脑；核验实际命令与预先合法计划、每笔电脑命令与策略/应答者、资金非负、日期推进和关键前缀/最终状态事件。
- 生命周期：暂停等待、恢复、重开取消、重置、全电脑待决策时新局替换为人类、电脑等待时退出、全屏、390px。打包页另验默认人类、全电脑自动行动、暂停、替换和退出。
- 首轮脚本在最后返回链接定位失败：游戏操作/导出已发生，但未计整轮通过；修正“模块集合”定位后完整重跑，最终只采集成功轮次。

领域2/3/4人分别在第96/175/291回合产生胜者，但不把长局领域结果当终局浏览器证据。混合UI代表性路线至65/66回合，未做终局胜者UI、所有非当前应答者的真实AI浏览器组合、所有角色控制排列或浏览器后台降频。原精度/RNG/图表输入、其他资产挂牌、特殊角色、原转盘、原退出调用栈/终局、小游戏表现/碰撞及原内存快照差异继续保留。
