# UI-06 · 事件与应答窗口

日期：2026-10-19。基线 `817abba`。本阶段实现及本地验证完成，未打正式发布包、提交或部署。UI-00～UI-05 的工作继续保留。

## 实现与业务边界

| 窗口 | UI 还原 | 现有业务接入 |
| --- | --- | --- |
| 新闻 | 原版 NEWS 渐变事件框、标题与变化明细 | 原有确认命令；公共拍卖新闻进入竞价，查看不扣款 |
| 命运 | 原版问号事件框、逐人取卡区域 | 保留已结算回执、取卡/放弃；换供卡者时清空选择，即使下一位也有同一张卡 |
| 魔法屋 | 原版场景及女巫静态图，抽取/十二效果/建筑/结果四种页面 | 已支持的效果继续使用；旧模式未开启的效果保留按钮并标明“当前模式未启用” |
| 拍卖 | 原版会场、主持人、五种金额与 Give up 图片按钮 | 当前应答者现金校验、加价、永久退出；PASS 单独保留，标为暂未接入，不映射为永久退出 |
| 反应 | 原版通用提示框和 YES/NO 按钮，保留明确中文动作 | 免费/嫁祸、目标、拒绝及暂停；应答者或目标集合变化时清空旧选择 |
| 债务 | 通用提示框、付款人/差额/明细与明确确认 | 原有破产清算命令；不增加自动卖地、免债或取消债务 |
| 资产处置 | 账本式回执、多人结算进度 | 保留公共资金/债权人/公司等原有说明，展示真实处置状态 |
| 认输 | 通用提示框与确认/取消；退出后独立选人页 | 拆为 `SurrenderPanel`，沿用父层确认状态；提交失败保留提示，退出后放弃附身不撤销认输 |
| 小游戏 | 复古外框、分数/时间条、原图开始/结果提示框 | 三种 SVG 玩法、坐标换算、计时、暂停、退出及点数确认沿用；没有改动引擎与碰撞规则 |

`GameWindowHost` 仍只显示一个可操作决策窗口。魔法屋接续说明随新闻、命运、反应、拍卖和债务窗口显示，保留原访客、当前座位、命运次数及日期不推进提示。不能靠关闭窗口跳过应答。窗口身份新增魔法阶段/建造应答者、反应阶段、小游戏阶段；小游戏每帧 tick、分数变化不会重置窗口或抢焦点。

| 项目 | 证据 / 阻塞点 | 保留方案与恢复条件 |
