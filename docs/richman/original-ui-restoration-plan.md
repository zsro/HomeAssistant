## 后续改动的约束

- 保留 640×480 原版逻辑布局、桌面/全屏和手机横竖屏可用性；关键操作不能依赖 hover。
- 必答窗口从最新领域状态推导，一次只挂载一个可提交实例；包括非当前行动玩家的反应、竞价与债务。
- 存档读取或联机重同步后清除过期输入草稿与旧 decisionId，恢复正确应答窗口；旧音效、动画回调不得重复触发结算。
- 视觉、本地业务、联网权限分别验收；接入联网不允许现有单机玩法失效。
- 发布状态独立核验：`6e84e79` 已包含 UI 改动及包，本次未核验生产。历史报告中的“未提交/未部署”仅是当次任务边界。
