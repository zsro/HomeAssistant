# S2-02 第四批设计：遮挡核验与地图点选建造

## Goal
核验第三批遗留的命中写入/形状来源/排序，在邻近模式增加地图点选、列表同步、确认建造的完整交互。
## Scope
In scope：固定源码核验、定点读取本地 MAP[26] 的格式/帧元数据、Web 场景像素点选、透明穿透/前景遮挡、误拖动/暂停防护、旧回放回归。Out of scope：未确认的原版遮罩映射、原版完整 440×440 命中图、扩大工人合法范围、新物品/资产规则。
## Core Gameplay
掷骰前使用工人 → 点击地图上邻近地块或住宅 → 列表选中并显示等级/归属 → 确认后免费建造 → 继续骰子。点选本身不消费、不增加命令，取消与重开同旧模式。
## Screen Structure
保留游戏地图和原目标列表；面板增加点击提示与所选地名/路格，地图显示选择圈。列表仍可选被遮住但在 v3 候选集合中的地产；点选仅是额外交互路径。
## Interaction Flow
客户端点转换成画布/世界坐标 → 从 Web 实际显示顺序最上层向下检查 → sprite 的 atlas alpha 非零即命中，透明处继续；地块使用当前可见菱形底座 → 被角色/地标/不可选地块挡住则不穿透 → 命中合法候选时更新本次 token 对应的 UI 选择 → 用户明确确认，由旧引擎二次校验。
## States And Feedback
未选择禁用确认；地图点击与列表选择同步，显示“已选择”文本；空白/遮挡点击不更改已有选择。暂停禁用点选、取消、确认；拖动只平移；选中后不强制移动镜头，定位按钮可跟进。取消/重开/新局 token 改变后不保留旧选择。
## Rules And Edge Cases
参考写入规则：0 字节透过，非 0 后写覆盖，按锚点偏移及边界裁剪。Web 使用已加载图集的 alpha 对应当前可见像素，地块底座沿既有菱形；文字/调试圈为 UI 注释，不参与遮挡。Web 排序沿 Pixi 对象的实际顺序，不声称复刻参考 signed-int16 qsort 或完整原版像素图。地图点选不扩大/缩小 v3 候选集合；设施/范围外/满级的像素阻挡而不触发选地。鼠标仅主键，捕获后画布外释放、pointercancel、拖动后释放、非当前 token 均不选择。
## Data And Technical Notes
v1/v2/v3 注册表、指纹、GameEngine 与合法集合不改，无规则变化故不新增 v4。选择 UI 状态按 effect decisionId 隔离；会话与回放不保存相机/选中状态。新增纯命中函数，从现有 ImageBitmap 一次抽取 atlas alpha，不转换/增加素材，不建第二个渲染循环。销毁清理所有已有资源和像素缓存。
## Delivery Slices
MVP：有证据的遮挡算法、地图点击与明确确认。Polish：透明穿透/遮挡/拖动/暂停/取消/重开/全屏/窄屏/旧回放及清理验收。Optional Enhancements：后续以本地 EXE 的真实加载入口定位对应遮罩，证据充分再以新规则版本扩展原版目标选择。
