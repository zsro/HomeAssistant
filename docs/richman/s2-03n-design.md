# S2-03n 公司营业首组设计

## Goal
让合法持股形成的经营权产生地图营业收入，再进入既有15日分红。
## Scope
本组接日本丰田59/60车辆服务费、SEGA102/103按已过天数营业费；合并核验六家公司入口。日产建造选地、三井保险、现场认股、三越/富士追加业务保留，旧商店/银行照常。
## Core Gameplay
买股成为经营者→其他玩家落点公司→按车辆/日期计算费用→神仙修正与反应→实际付款记公司本期/累计→15日股东分配。
## Screen Structure
新增公司营业结算面板，显示公司、来访者、最终付款人、计费依据、银行/现金实付、账本变化及不足退出。沿用反应面板、股票和分红面板。
## Interaction Flow
经过不收费。落点查看经营权，经营者本人/无人经营免付；丰田步行不收费，SEGA开局已过0天为0。应付经免费卡/嫁祸以及衰神代付选择最终付款人，自动结算后确认继续。
## States And Feedback
账单明确正价、修正价、实付及豁免原因。暂停不能应答/确认；重复token、错玩家和非法目标原子拒绝；重开清账单。
## Rules And Edge Cases
公司经营者不直接收钱；实际收款同时加入公司+28/+2c，不入公共资金。收费只取cash→bank，不预卖持仓；不足按已有明确Web退出规则归还持仓、彩票和库存。原强拍未复刻。公司收费无同盟免付或经营者住宿/衰神免付过滤。梦游不屏蔽代码0的收费；现有原落点道路伤害/神仙顺序保留。
## Data And Technical Notes
新v27及独立指纹；账单在news.business随G7恢复。新companyFee反应续接，不改旧租金/税款。新语义不消耗随机数，语音/动画随机未复刻，物价固定1。
## Delivery Slices
MVP：核验目录、两费与反应/账本闭环；Polish：面板、领域边界、原图正常速度合法获取/收款/15日分红与回放；Optional Enhancements：下一批日产/保险/现场认股独立核验。
