# G7 实施设计

## Goal
完成时光机、传送机、核子飞弹三项及合法科研获取，使用独立g7/v13保留v12；43项实现后进入统一自动测试，验收仍以实际证据登记。

## Scope
优先时光机：每玩家最近一次出发前快照、全局资产/地产/状态/股票恢复、扣除道具、取消预览、回放。随后传送玩家/游离物件/建筑、核子440投影视窗清产权/建筑/物件与住院。2/3/5级研究所免费生产等待5次自身行动。特殊角色、逐像素命中、原版完整日期与动画不纳入。

## Core Gameplay
研究所选产品→五次行动后入包→掷骰前使用→选对象/目的地→预览→确认扣除→真实效果→继续行动或落点结算。时光机需要当前及历史背包都持有，避免历史无道具时下溢；不能在结束后的对局回溯。

## Screen Structure
沿用研究、库存、卡片面板。时光机展示记录轮次与恢复范围；传送两级选择（对象、目的地）；核子展示受影响建筑/玩家/物件。普通地图/全屏/窄屏保持。

## Interaction Flow
begin生成决定令牌，选择与预览不改变状态；confirm重新核验来源、目的地、库存和revision；cancel不耗物。自行传送直接进入落点流程（银行/商店/地产/神仙/地雷），不掷骰、不逐格走、不扣炸弹移动格。传送他人/物件不立即代替对方结算。

## States And Feedback
时光机没有可用历史时禁用并解释；恢复后清除所有旧历史，防止从未来再恢复（Web防循环约定）。日志与命令/revision/serial保持单调，游戏轮次及经济状态可回退，随机数发生器继续而不回滚。传送保留最接近原朝向的合法出路，携带物跟随；核子含自己可能结束当前移动资格。

## Rules And Edge Cases
固定参考提交ec7d70e693059d1e781d9d1cc2ad7f36d360d39e，来源B级无Windows对照。时光机保存函数记录全体玩家/卡片/工具/池/道路物件/持仓/股市/日期/地图缓冲，原生RNG不在快照；Web只恢复明确领域数据而非JS对象/回放元信息。历史在正常出发前和自身传送前更新；恢复后扣历史库存1件。传送地产至同类待售且0级地，移产权/楼级/类型，研究取消与价格状态留原地为保守Web规则。核子范围是440方形投影锚点，不是全图清空；清产权建筑与研究，玩家住院3次/车辆损毁，无反制窗口；范围内游离神仙和附身移除。

## Data And Technical Notes
快照只包含领域字段，不递归含历史；G7注册表/研究产品独立于旧指纹。G5研究入口按g7存在扩展表，旧模式不变化。新工具效果支持两段Target选择；状态与每个效果记录入回放。v12遗留问题只在有证据时修复并说明兼容边界。

## Delivery Slices
1. MVP：三项合法获取、引擎/UI及跨组联动。2. Polish：43项统一引擎/组件/旧回放与浏览器验收，修复实际失败。3. Optional Enhancements：精确日期、原版运行对照和专属动画，独立登记。
