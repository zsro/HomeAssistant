# S2-02 第七批：均富卡

## Goal
复用卡片经济新增全体现金平均，完成多人获取、预览、消费和回放。
## Scope
独立 v6；均富卡 200 点/总供应 1，开局 0，共用卡片 15 格。保留 v5 和所有旧规则。随机发卡、售回、仇恨、音频继续待办。
## Core Gameplay
攒点 → 商店购买 → 掷骰前预览所有未破产玩家现金 → 确认各分得向下取整平均值 → 返池 → 继续道具/骰子。不按距离选人。
## Screen Structure
商店/背包新增均富卡；预览列出全部参与者、原现金、平均后现金、舍弃余数和存款不变说明；旅途记录显示人数及平均额。
## Interaction Flow
使用按钮打开全员预览；确认消费 1 张，取消不消费；满库存/缺点数/售罄禁购；确认后仍为掷骰前。新局使用 v6，旧模式保留。
## States And Feedback
暂停禁用提交，重开清空卡片；相等现金仍可消费并提示；重复、过期、错误操作者/伪造目标拒绝；预览随决策令牌隔离，全屏/窄屏可操作。
## Rules And Edge Cases
参考循环 i<num_players 且 who_plays!=0，包含使用者，不检查距离或任何状态天数。当前 Web 对应全体未破产玩家；未来不能任意加入住院/旅馆排除。仅现金参与，整数除法舍弃余数，不给任意玩家余款；安全整数输入通过 BigInt 汇总避免中间和溢出。不模拟参考 int32 溢出。
## Data And Technical Notes
独立均富卡效果注册，self 目标只作命令身份校验，实际参与者由引擎枚举，UI 不能提交自选名单。保留 v5 均贫卡两张供应字段，v6 新增均富卡一张供应，持有总数共用既有 cardCount。原版消费后立即处理；Web 增加可取消确认是显式交互差异。修改前冻结 v5 实际浏览器回放及状态/事件哈希。
## Delivery Slices
1. MVP：源码/规则、v6 领域结算与库存回收。2. Polish：全员预览、多人真实 UI 购卡/消费和旧版本回归。3. Optional Enhancements：后续新卡、随机获取与原版表现；不重做像素遮挡。
