# S3-02a：主动遥控骰子与机器工人策略

**S3-02a 已完成；S3-02 其他高级策略仍待后续分组。** 本批新增宿主策略 `tools-v1`，`basic-v1` 继续独立保留。游戏规则、指纹和引擎保持 `japan-events-candidate-v44 / f9dbb7e9`，不创建 v45。策略依据是已有合法命令、公开道路、库存和资金，不宣称原版 AI 等价。

## 设计范围

新局仍默认全人类；座位选择“电脑”后，可选择“基础：购地与资金”或“道具：遥控骰子与机器工人”。同局电脑使用同一个策略版本；本批没有逐电脑混用不同策略、中途托管或难度设置。电脑面板显示本次与上次理由；暂停、重开、退出保留原生命周期。

出发前先考虑工人，再考虑遥控骰子，条件不满足则正常掷骰。使用分 begin/confirm 两条既有命令，各等待600ms；begin不扣物品，confirm重新计算当前合法目标后才消耗。目标不存在、归属变化、满级或库存不足时取消，不靠重试循环。人类不能越过电脑控制区提交确认；其他玩家作为实际应答者时仍沿原 payer/responder 规则。

## 规则与策略登记

| 编号 | 内容 | 依据/界限 |
| --- | --- | --- |
| R10-01a-tools | `tools-v1` 与 `basic-v1` 分派；策略只进宿主配置与回放control | 自定义宿主策略，世界/游戏规则不变 |
| R10-02a-tools | 工人只选附近合法、自有、可加盖的普通地产 | 复用 `nearbyWorkerTargets`；按基础租金增量排序，同分按地产ID字典序；不是原像素遮挡或原AI |
| R10-03a-tools | 遥控骰子评估1～6步公开道路 | 仅步行单骰且非停留/乌龟/行动锁定/旅馆；不模拟引擎、不读取未来事件或快照 |
| R10-04a-tools | 落点价值与现金余量、物价和风险 | 可负担待售普通地产40、自有可升30、通过现金门槛的自有满级10、点数格20、其他0；敌地产−100、可见路障/地雷/炸弹路径−1000 |
| R10-05a-tools | 库存、有限货架及30点补购 | 库存为0、有货、足额点数才购一个遥控骰子，然后离店；机器工人不在商店购买 |
| R10-06a-tools | 两阶段确认重算与取消、人机归属、暂停/重开/退出失效 | 复用Session调度；每次提交当前revision，不保存未检查目标 |
| R07-01a-tools | 道具消耗与费用/供应 | 工人无现金费用、加盖1级并保留产权；遥控骰子扣1并归还有限池，指定点数不抽RNG；旧规则不修改 |

遥控骰子只有最佳分≥30、并比至少一个其他点数高10分才使用；同分选较小点数。分岔时按剩余最多六步重新选择最高分路径，同分选较小路格，超过六步或行动受限继续基础策略。费用只用于启发式排序：普通购买以 `(动态原地价 + 楼级×建造价)×物价`，升级以 `建造价×物价`，要求付费后现金至少1000。实际付款仍使用引擎报价，不在策略中扣钱。

策略把全部敌方地产视为风险，不押注神仙、同盟、免费卡等免租；地图事件只计已公开的点数格，不预测新闻/命运、未来行情或随机奖励。路径中遇到已显示的路障、地雷、炸弹一律保守避开，不主张复刻原版每种物件的精确经过风险。携带炸弹计时、银行拦截、神仙经过效果等未纳入精确前瞻，可能使最终可行收益变化，后续命令会重新判断。

工人免费加盖优先自有普通地产，既有规则允许的敌方或无主地不列为策略目标；本批不主动科研获取工人，不操作大型建筑研究。合法获取路线保留开局每人一个工人/遥控骰子和正常30点商店补购；不注入物品，也不虚构工人商店货架。

原图UI使用正常动画、真实人类点击与Session自动命令，只有鉴权fixture。计划只供合法路线安排；成功下载后独立检查实际电脑动作、库存、费用、产权/楼级、点数/供应、RNG边界及关键前缀/完整状态事件。

首次领域测试错误地假定起点1一定值得使用遥控骰子；六种点数同分时策略应保留道具。把“可用遥控场景”探针移到起点2后测试通过，没有为测试修改策略阈值。失败轮次不计通过。

## 保留差异与下一步

本批不是完整高级AI：其他主动卡片/股票、研究、竞价、融资和精确长期收益仍待后续策略组；原版AI随机/仇恨与难度不等价。目标变化与取消主要为领域测试，正常UI中其他座位不能在道具待确认期间改写世界；不宣称所有状态或角色排列都已完成浏览器验收。

S3-01基础候选、S2-03/04/05、43物品/36新闻/日本37槽命运和历史回放保持。原精度/RNG/图表、其他资产挂牌、特殊角色、原转盘、原退出调用栈/终局、小游戏表现/碰撞与原快照差异继续保留。退出后拍卖不能救活玩家，公共所得不能代付原债。

下一S3-02b优先把免费/嫁祸反应与租金风险作为一组策略增量，独立新policy并保留basic-v1/tools-v1及回放；股票与更多主动攻击后续分组。无新游戏语义继续v44。
