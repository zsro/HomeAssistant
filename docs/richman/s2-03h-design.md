# S2-03h 资产命运设计

## Goal
在原日本地图命运格完成地产补偿、逐人取卡、股票损失/变卖的可玩闭环，并保持v20及全部旧回放。

## Scope
v21新增0/1/5/8/9五项，累计21/37日本命运槽。保留v19新闻与43物品；日历/利息/贷款到期、原破产强拍、完整公司/保险、其他命运不在本批。

## Core Gameplay
正常移动或自身传送落到命运格，按37槽顺序筛选条件。0/1在己有普通地产中随机选择并补偿；8/9处理当前持股；5按座位依次向仍在局、有卡的其他玩家选择一张卡或放弃该玩家，最后展示汇总。

## Screen Structure
复用命运侧栏，新增逐人取卡阶段：当前供卡者、可选卡名、确认取卡、放弃本位。展示已完成明细，未完成时不写“全部已结算”。资金/地产/持仓与库存继续显示在已有界面。

## Interaction Flow
道路/神仙 → 命运条件检查 → 即时结算或逐人选卡 → 汇总确认 → 回合结束。每次选卡使用独立token，暂停不能提交，已处理供卡者不能重复取。取消重开对话框保留进度；确认重开恢复新局。

## States And Feedback
继续使用fortune阶段；decision.collection存在表示尚有取卡选择，普通ack拒绝。每次提交原子变更背包，最后只确认结果；明确地产前后、补偿现金、股票减少及资金去向。

## Rules And Edge Cases
0只己有已建普通地产，补level×原始upgradeCost现金，建筑清零/类型清零、产权保留。1只己有空普通地产，按动态basePrice补现金并收回产权。5人类选卡，按座位跳过自己/淘汰/空包，拘留者仍参与；卡满15先丢最便宜首槽再接收，转移本身供应净零、弃卡返池，不触发抢夺卡仇恨/反应。8每股种floor(持股/10)，所得公共资金；9全部持股卖出所得进银行。8/9用+70命运抵抗，code1取消、code2不扩大损失；强制操作不受休市/停牌限制，更新公司排序。沿用Web持仓总成本按比例截断、整数分价格；不把它说成原版浮点平均成本字段。五项没有直接扣款，不引入破产调用；贷款额不改，资产能力按已有公式动态变化。

## Data And Technical Notes
独立v21规则/指纹及assets-fortune模块；旧v20指纹/结构不变，v21继承相同新闻/命运初始化。扩展命运结果可选资产记录，逐人取卡决策保存剩余供卡者/候选/累计结果。时光机继续复用fortune世界快照；命令、token与随机数不倒退。来源使用固定提交，ASM优先。
