# S2-03a：随机得卡地点

## Goal

玩家在日本地图98号格停下时，从公共剩余卡池免费获得一张卡，看到获取/替换结果，并可在之后的合法行动使用。

## Scope

In scope：事件目录现状核验；事件码13的落点触发、剩余数量加权抽取、15格满包替换、日志/界面反馈、v14与回放测试。Out of scope：新闻/命运全部效果、小游戏、乐透、魔法屋、完整日期/结息及原版动画。它们继续单独登记，不以空效果代替。

## Core Gameplay

原图正常出发 → 经过不触发 → 停在98号格 → 抽卡及库存/卡池原子结算 → 显示卡名与替换情况 → 正常结束回合 → 下次合法行动使用卡片。胜负规则继承v13。

## Screen Structure

复用地图、玩家资产/库存、操作区和最近记录。在操作区显示本次落点得卡结果及规则说明，不新增确认弹窗或新素材。

## Interaction Flow

新建“地图事件候选”对局；正常掷骰或合法遥控骰子抵达98号；自动结算后可查看背包。下一玩家、暂停/继续、全屏、重开和回放继续使用现有入口；v13独立模式保留。

## States And Feedback

成功显示卡名；满包显示移除的最便宜卡（同价取最先槽位）；公共池空时显示未获得卡，不抽随机数、不丢卡。梦游跳过此特殊地点。暂停停止动画；重开清除反馈并恢复初始库存。

## Rules And Edge Cases

事件码来自原地图statusBits低8位，不把kind当事件码。仅落点触发；停留卡不重复结算，自传送依v13既有落点规则触发，传他人不触发。雷/爆炸中断优先，神仙沿用已有落点顺序；该跨领域顺序属于Web候选。重复命令/回调不重复授卡。抽取按剩余张数加权；先抽后满包替换，退回旧卡再扣新卡；支持抽到同名卡。时光机恢复库存/卡池但不回退RNG及历史日志，沿用v13。

## Data And Technical Notes

新规则japan-events-candidate-v14继承全部v13能力，独立指纹。复用现有赠卡算法和槽位/供应守恒；新增结构化地图得卡事件，界面从当次事件生成反馈，不增加需要时光机快照的新领域状态。原版rand替换为既有确定性Web采样器，未声称Windows逐随机值等价。无数据库或资源重导。

## Delivery Slices

1. MVP：源码与地图证据、版本接入、实际得卡和回放、领域边界及原地图浏览器。
2. Polish：原版图像/声音与典型运行对照，保持玩法版本边界。
3. Optional Enhancements：后续按证据接新闻/命运及日期；独立增量，不自动勾选S2-03完成。
