# G5 设计：范围建拆、道路攻击与研究生产

## Goal
一次交付七项，累计36/43已实现；18/43验收基线保持，自动测试集中在43项全部实现后。

## Scope
新`g5`/v11复用G4建筑、G2行动状态与G3库存/关系。三张建拆卡、地雷、定时炸弹、飞弹、工程车；研究所开放工人和工程车生产。其余科研产品在G7接入。神仙、保险、特殊角色和专用动画未实现。

## Core Gameplay
商店积点购买六种商品→背包选择目标→预览影响→确认消费。工程车通过自有4级研究所免费生产，等待5次自身行动后自动入包。玩家行走时携带炸弹计时/转交，落点触发地雷或拾取炸弹；爆炸打断行动并住院。工程车落点结算后拆除非己方建筑。

## Screen Structure
沿用卡片列表、预览确认和地图定位。新增研究生产选择/确认、道路物件和头顶携带标记、生产/工程车期限面板，建筑标签展示研究剩余数。场景默认v11，模式选择保留v10及旧模式。

## Interaction Flow
选卡→选地块/道路/自己→查看受影响对象→确认或取消。空大型用地使用天使需选择建筑类型。商店不出售工程车；停在自有研究所且当前无项目时选择工人/工程车，确认后不扣钱或点数。等待期间不需停在研究所。

## States And Feedback
沿用effect决策令牌、暂停/错误反馈/命令去重；研究请求带预期revision，所有新计时都由命令边界推进。地雷/炸弹放置后占用有限供应，清理时才返池。研究/爆炸/转交/拆除写日志；新局重新初始化。无自动测试或浏览器验收结论。

## Rules And Edge Cases
怪兽仅非己方且已建地产；天使/恶魔作用普通同名街区或单大型地。飞弹使用投影200×200锚点候选范围，逐对象一次命中、包括使用者；删除道路物件而非额外引爆。38格炸弹先减后判爆炸再转交，银行操作不另扣格。工程车1骰、含启用当次7次自身行动，梦游暂停；不免疫爆炸，原车辆入包，正常到期有库存才恢复。原版像素命中、日期和特殊角色单列差异。

## Data And Technical Notes
新增`g5-catalog.ts`与`g5.ts`，v11扩展注册表/指纹；旧版本不创建G5状态。复用已有PropertyState.research，新增任务ownerId，只由v11写入。领域层负责预览与确认复算，Scene只画候选标记。研究入口允许站在自有研究所的idle/turnEnd请求，是明确Web交互约定；项目不可中途改选。

2. 三卡建筑结算与有限池、道路携带/攻击、工程车/科研依赖。
3. UI/回放命令接入、静态审阅和类型检查。
4. 本轮仅登记待验收清单；随后G6、G7、43项统一验收。
