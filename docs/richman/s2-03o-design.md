# S2-03o 日产建造与现场认股设计

## Goal
使日产落点建造、收费及公司现场现金认股成为可继续正常回合、分红和回放的完整流程。
## Scope
新增v28：日产67/68全图地产/大型用地选择、本人免费两次/他人一次后收费、取消费用；代码0四家公司现场认股。保留v27全部能力。完整保险费用/赔付、其他日期及强拍不在本批。
## Core Gameplay
落点日产→选择地块及空大型用地类型→先建造→费用修正/反应/实际收款→认股或离开→结束回合；买股改变后续经营权并参与既有15日分红。
## Screen Structure
公司服务面板含目标列表、定位、空地类型、前后楼级和费用预览；认股面板含现金单价、余股、单次上限与数量；营业账单沿用现有面板。
## Interaction Flow
无人经营不建造直接认股；本人建造免费且尝试两次；他人先建一次，随后费用反应。取消选地本人免费、他人1000元。认股单次确认后离开，也可直接跳过。
## States And Feedback
暂停禁用操作；非法目标、类型、数量、过期token和错玩家拒绝且不修改领域状态。零余股、梦游、退出或现金不足跳过认股。重开清新账单。
## Rules And Edge Cases
selector0x86可滚动，无归属/楼级过滤；Web全图列表替代像素选中。满级可选、建造无变化仍按地价收费。楼型/产权不变，空大型用地自选类型。研究任务沿现有规则保持或取消。认股单价floor(资本/10000)、现金/1000股/独立池三重限制，不用银行、行情配额，不计公司收入；持仓总成本继续用既有Web整数账本。
## Data And Technical Notes
独立v28指纹，新增认股池与最近账单随news.business/G7恢复；旧v27状态不加字段。普通买卖回收认购股进入市面池，认股池不补回。源码跨版本证据与Web选择/成本约定分开登记。
## Delivery Slices
MVP：证据和两入口；Polish：领域边界、面板与原地图合法路线实际浏览器/独立账目回放；Optional Enhancements：保险合同/赔付及未核验公司活动。
