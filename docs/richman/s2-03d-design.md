# S2-03d 新闻经营组设计

## Goal

接入地价调整、公共拍卖与地产税，让新闻变化影响后续购地、估值与资金，而保留旧回放。

## Scope

v17新增新闻6/7/12，继承v16八条。新增每块地产动态基础地价；公共竞价无卖方玩家；地产税现金再银行并处理退出。原版完整破产随机强拍、贷款、日历/结息、原图像不在本批，候选差异明确登记。

## Core Gameplay

新闻格依序选中事件→6自动调整同名街区或单块大型地价；7显示标的后进入轮流竞价；12按全员地产估值征税→显示结果→继续或结束对局。

## Screen Structure

复用新闻、地产、资产、拍卖面板。新闻列明地价前后/税基实付欠付；公共拍卖说明钱进入公共资金。默认v17，保留全部旧模式。

## Interaction Flow

新闻7先查看标的再进入竞价，合资格玩家含触发者，现金大于底价、无拘留/冬眠/梦游/住宿/停留限制；加价或退出，结束后结果确认。新闻6/12自动结算，确认不重复处理。暂停和过期token沿用命令防护。

## States And Feedback

区分“待拍卖”和“已结算”；无人参与/全部退出则流拍，产权不变。税款不足显示实付和未付、破产释放与胜者。非当前竞价人不能操作。

## Rules And Edge Cases

6随机普通+大型一块，普通按同名整街调整基础地价×1.3截断写16位，大型仅本块；建筑费/租金表不变。动态价格用于购买、购地卡、拍卖底价、估值、地产税、大型初建；传送时价格留在原地块。12按全员未退出玩家总(地价+楼级×建造费)5%截断，现金优先存款补足，实收进公共账本，不用反应卡/神仙租金免除，不先卖股救税；不足复用Web退出清理，股票归池，不作为未缴税补款，原破产强拍留待补。7从待售普通/大型随机选一块，底价floor(动态地价×(1+楼级/2))，轮流加价为既有Web交互候选。无日历语义升级。

## Data And Technical Notes

动态basePrice仅v17地产状态存在，旧快照/指纹不变。时光机随经济快照恢复价格与公共资金；扩展新闻日志、公共拍卖续接与原有退出清理复用。无数据库或素材变动。

## Delivery Slices

1. MVP：三新闻/相关费用、测试、原地图合法路线与真实回放。
2. Polish：原版竞价时序与破产强拍运行对照。
3. Optional Enhancements：继续新闻目录及日期/贷款，不将本批等同完整经营系统。
