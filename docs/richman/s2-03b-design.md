# S2-03b 新闻首组设计

## Goal

在日本新闻格触发可追溯的资金/股票新闻，玩家看清全员变化后继续回合。

## Scope

开放news:11所得税、23存款红利、24全市场下跌、25全市场上涨；建立36项候选序列、游标、跳过与独立v15。其余32条未实现，明确跳过；日期/结息、贷款、乐透奖金分配及原版新闻图像不在本批。

## Core Gameplay

正常出发或合法自传送→停在13/61/94新闻格→依序选择已开放且符合条件的新闻→原子结算→显示各人金额/各股行情→确认后结束回合。

## Screen Structure

复用地图、资金、股票、库存。新闻面板显示标题、结算明细和“继续回合”；说明四条开放范围。独立v14模式和全部旧模式保留。

## Interaction Flow

默认新建新闻候选对局；经过不触发、梦游跳过；落点触发后冻结交易与其他行动，仅允许暂停、确认、重开。新闻没有撤销按钮，确认不再次结算；重开需已有确认框。

## States And Feedback

展示已结算变化，不用视觉动画推进经济。暂停禁确认；过期token与重复确认不重复修改。没有可执行候选时有跳过记录并结束，最多扫描36项，不死循环。

## Rules And Edge Cases

原初始化按剩余候选秩不放回抽取36编号、游标0；逐项推进，包含成功项，到36回绕，不每轮重洗。Web沿用确定性采样替代rand，未开放32项跳过会改变原版分布，明确候选子集。所得税=现金5%向零取整，退出玩家排除，设施中玩家仍参与；税款记入公共资金账本，尚不接乐透。红利=存款10%取整入存款，现无贷款系统（原有贷款者不参与）。全12股按基准±10%/既有价格刻度，覆盖趋势为本期，下一行情边界清除，不触发玩家攻击反应/解盟。持仓与成本不变。时光机恢复序列游标/公共资金及经济，随机源和历史日志仍不回退。

## Data And Technical Notes

v15继承v14及43项；新增NewsState与新闻决策token，消息和回放版本化。无DB/素材重导。旧规则没有新闻状态，保持原哈希。

## Delivery Slices

1. MVP：四新闻、原地图触发/确认、领域边界、原图组合与回放。
2. Polish：原版运行对照、原图像/音效、其余条件和效果。
3. Optional Enhancements：经核验后接日期/银行/乐透，不用本批红利冒充定期结息。
