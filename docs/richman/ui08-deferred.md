# UI-08：原版差异与业务挂起清单

> 文档整理（2026-10-19）：本页保留阶段记录/专项参考，历史状态与下一步不代表当前排期。现状见[项目总览](README.md)，后续任务见[路线图](../richman-roadmap.md)。

这是总验收边界，不代表以下项目已实现，也不隐藏原版入口。当前已支持业务继续可用；恢复条件满足后另立接入任务。来源详见各阶段审计与实施文档。

## 业务挂起

| 项目 | 当前界面表现 | 恢复条件 |
| --- | --- | --- |
| LOAD / SAVE | 顶栏读档、存档及主菜单 LOAD 保留，点击显示未接入；回放独立命名 | 版本化存储、恢复边界、损坏/过期处理及恢复回放验证；原生存档兼容另行核实 |
| 额外可玩角色、其他地图 | 当前四名角色和日本地图；开局其他原版角色占位标记不可用 | 身份/素材/地图规则确认，不能仅凭有头像允许提交 |
| 股票/卡片/道具挂牌 | 出售分类保留并禁用，标记未接入 | 独立核实交易规则、所有权和费用；已有地产挂牌不受影响 |
| 拍卖 PASS | 原图入口保留并禁用，不等同 Give up | 确认临时跳过语义及轮转规则后加入命令 |
| 旧模式未启用的贷款、魔法等 | 对应入口保留“当前模式未启用/暂未接入”提示 | 已支持模式继续可用；不能为显示按钮而绕过版本门槛 |
| 人物其他页的未实现资料 | 保留明确占位，不伪造数值 | 核实字段含义和规则数据来源 |

## 视觉、素材与演出差异

| 项目 | 当前交付 | 暂缓原因及恢复条件 |
| --- | --- | --- |
| 字体、精确字距、内部表单坐标 | 原版背景与 Web 文本/表单，简体标签；可访问 DOM 与焦点框 | 逐状态原版运行证据不足，字体/字距/遮挡需另核实；不宣称像素一致 |
| 手机布局 | 可读文字、常显工具名称、至少 44px 的主要触屏控件，允许纵向滚动 | 原版没有对应手机布局；Web 适配属于交付设计 |
| 小地图、日历 | 原图季节底图，Web 道路/产权/相机框与日期网格 | 未复刻全部原生细节；相机和日期业务已接入 |
| 设置和选人 | 原版标题/设置图、四名角色头像，Web 操作控件及高级区 | 设置内部热区、完整原生选人场景未核实；原图不能当成假按钮 |
| 银行、设施人物动画 | 静态场景、金额键盘和真实名单/期限 | 原人物口型、逐角色医院/监狱姿态和位置未完整确认；需逐帧身份/时序证据 |
| 公司、认股、研究、处置专用构图 | 统一经营账本外框、现有字段和真实回执 | 原版专用内部布局未完全核实；保持当前可用表单 |
| 新闻/命运逐条插画 | NEWS/问号原框，真实标题与结算文本 | 本地与参考 Data 索引不同；须逐项映射，不能猜偏移 |
| 魔法转盘、保险减速、主持人/店员口型 | 静态原场景、全部已支持动作及结果 | 时间轴/热区/中断条件尚未完整确认；不得改变随机或命令时序来伪造演出 |
| 拍卖竞价席、倒计时及反应演出 | 原会场/金额按钮、真实应答者及提示框 | 原生状态与时序证据不足；已有竞价与反应业务保留 |
| 三个小游戏内部原图 | 统一原版风格外框/开始/结果，内部沿用可玩 SVG | 原人物像素碰撞、素材时序和输入坐标需成套移植 |
| 原版结局动画 | 胜者、破产及资产结果账本、新局/回放入口 | 结局事件与动画时间轴未移植 |

## 图片完整性口径

- 当前运行白名单 169 个文件全部存在、哈希一致，124 张 UI 图片实际解码通过。13 种工具图已映射；原版卡片格使用卡名文字，不把 30 种文字卡片误记为 30 张缺图。
- 以上逐事件插画、角色姿态和动画缺口尚没有逐张身份清单，数量明确标为“待核实”，不填零，也不把整个 Data/Panel 目录都当成已识别素材。
- UI-00 审计 450 帧与后续补充审计是证据范围，不等于运行资源数量。未使用帧保留在审计联系表；实际发布按白名单执行。
- 已核实入口与已有功能完成本轮验收；这些差异仍需单独跟踪，因此结论只能是“本计划 Web 必做界面和发布准备完成”，不能写“全部原版 UI 已 100% 复原”。
