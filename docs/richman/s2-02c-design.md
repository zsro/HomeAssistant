# S2-02 第三批设计：邻近建造候选版

## Goal
沿第二批线索核验目标选择，开放从多个邻近普通地产中选择一个免费建造，并保持 v1 遥控骰子、v2 当前地块限定版及回放。
## Scope
本批实现独立 v3 候选模式、固定方向投影的锚点筛选、列表选地与地图定位、确认/取消及回放。原版逐像素遮挡命中、视角旋转、特殊建筑、更多物品、工人售卖不在本批范围。
## Core Gameplay
每人仍有 1 工人和 1 遥控骰子。掷骰前打开邻近目标列表，选择普通地产，定位查看，确认消费 1 工人免费升一级；取消不消费，建造后仍可掷骰。
## Screen Structure
默认新场景为邻近建造候选版；新局菜单保留 v2。列表显示地名、道路编号、归属和升级等级，用唯一地产 ID 区分同名地块，选择时定位地图。常驻提示范围不随拖动/缩放变化。
## Interaction Flow
权威引擎根据角色所在道路坐标生成候选 ID → 面板显示目标 → 明确选择、可预览 → 确认再次校验候选、库存、token、操作者与阶段 → 原子消费及升级 → 返回掷骰前。
## States And Feedback
没有未满级目标、无库存、暂停、非掷骰前禁用；选择中禁止掷骰。取消/重开清空 UI 选择；确认后跟随角色恢复。全屏/窗口尺寸与地图操作不改变目标集合。
## Rules And Edge Cases
源代码证实 440×440 命中视窗、方向相关投影表、道路/地产/图形遮罩按顺序覆盖，不能以欧氏半径代替。v3 显式 Web 约定：方向 0、角色道路坐标为中心、普通地产锚点投影在 [0,440)² 内才列入；不是原版像素命中的等价实现。保留 v2 的任何归属、0–4 级、无钱/点数/RNG 消耗、满级拒绝不空耗、工人不进骰子池；设施和中心网格以外拒绝。多路格只列一个地产 ID。
## Data And Technical Notes
`japan-tools-candidate-v3` 与新效果 ID，独立指纹包含方向 0 的 29×29 整数投影表和四项子格系数，沿已固定提交抽取并验证源码 SHA。引擎与会话使用同一纯函数；列表使用会话权威候选，不从浏览器相机推断。v1/v2 模块与指纹不变，状态/回放容器仍 v1。无素材/数据库/鉴权变化。
## Delivery Slices
先核验并归档源位置与表 → 引擎/回放/会话 → 列表及定位 → 边界与旧回放测试 → 原地图正常速度浏览器验收 → 更新登记与下一步。后续优先核验遮罩来源与写入算法，再决定是否扩大原版选择器范围。
