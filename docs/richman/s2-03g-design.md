# S2-03g 命运资金与库存组设计

## Goal
在保留 v19 全部新闻、43 项物品和历史回放的基础上，让原日本地图命运格产生有证据的结果。

## Scope
v20 开放命运 17～32，共 16 个处理函数。15 个资金奖惩和全部卡片/道具变卖；加入神仙修正、车辆恢复步行、库存供应返还。其余命运、日期/结息、贷款到期、保险公司完整业务、原破产强拍不在本批。

## Core Gameplay
正常移动或传送自身落到 2/19/45/66 号命运格，轮选可执行事件，立即原子结算并展示明细；确认后结束回合。经过、梦游不触发。

## Screen Structure
沿用地图、玩家资金/库存、车辆和日志。在侧栏增加命运结算面板，展示事件、实际收支或变卖点数、神仙修正、当前开放范围；模式选择保留 v19。

## Interaction Flow
落点完成道路/神仙结算 → 轮选命运 → 结算 → 暂停/恢复或查看明细 → 确认继续回合。暂停时禁确认；旧决策不能重复确认。重置恢复初始库存和轮选序列。

## States And Feedback
idle/moving → fortune → turnEnd/finished。资金不足沿用 Web 破产清算，显示实付、欠款和胜者；空库存照常展示 0 点。日志、回放记录候选跳过、游标、神仙判定、前后资金/库存/车辆。

## Rules And Edge Cases
原序列 37 槽，后 4 槽按地图映射到 49 项全局分派；本批只启用 17～32，最多扫描 37 次，无重洗。资金固定物价 1；奖入现金，罚先现金再存款，实收进既有公共资金。股票不作为罚款自动救济。神仙使用 +70 资金与 +72 事件抵抗两张表，取消/加倍分开；变卖 code2 不加倍。装备机车/汽车/工程车也按工具价卖出，研究工具无供应池，点数按 uint16 回绕。未实现保险保单，费用不虚构赔付。随机数沿用 Web 种子算法，非原 libc 逐位一致。

## Data And Technical Notes
新增 v20 规则/指纹和独立 fortune 状态；新闻初始化后初始化 37 槽以冻结旧版本。时光机保存/恢复命运游标；随机序列不倒退。原图合法命令浏览器路线与直接状态领域测试分开记录，不将引擎或小地图结果当浏览器通过。

## Delivery Slices
1. 固定提交源码核验、17 码/49 分派盘点与来源摘要。
2. v20 引擎、结算面板、车辆/库存/神仙联动。
3. 领域边界、旧回放与版本矩阵、原图合法路线浏览器；仅报告实际运行结果。
4. 更新规则登记、验收数和当前接续卡。
