# G3 / S2-02 第十批设计

日期：2026-10-05。六卡实现已落地，详见本组报告。用户要求全部43项实现后统一自动测试；当前24项实现、18项浏览器已验收。

## Goal

在现有18项之上整组接入抢夺、复仇、嫁祸、免费、免罪、同盟，形成合法获取、库存、触发/选择、消费、状态恢复及回放闭环，目标24/43。

## Scope

范围内：独立v9、卡片槽序/转移、可暂停的反应决策、同盟关系及期限、G1/G2有证据的触发点、租金反应及被转移付款者债务。范围外：像素命中、特殊角色、G4/G5未开放攻击/建筑、原版音画、完整AI/日期系统。价格/池及抢夺、同盟、被动卡入口已核验固定参考函数，来源与Web候选边界见报告。

## Core Gameplay

攒点购买 → 掷骰前选择抢夺/同盟或持有被动卡 → 攻击/租金触发 → 明确提示轮到受影响玩家应答 → 依证据顺序结算 → 恢复原行动。沿用地产资金、破产与最后存活者胜利；重开重置库存/关系/应答。

## Screen Structure

侧栏新增六卡库存与商店；主动卡可取消预览，反应面板显示发起者、应答者、原因、卡片消耗和结果；角色列表显示同盟对象/剩余行动计时。地图保留，反应期间普通掷骰/结束/用卡禁用。

## Interaction Flow

1. 默认新局v9，保留v8和全部旧模式；新卡初始0。
2. 商店购买追加到15格共享卡包的尾槽；使用删除首个匹配槽并压紧。
3. 主动卡选择/取消，确认后才消费。抢夺可选卡或库存工具一件，先转移后消费；满包先替换首张最低价卡，道具9个上限收取失败仍让对方失去道具。
4. 状态攻击按已确认的免罪→嫁祸→效果→复仇入口接入；免罪/复仇自动，免费/嫁祸可选；改向集合含远处/设施中的未破产普通玩家，无递归反击。
5. 租金是否开放免费/嫁祸遵循入口阈值与资金条件；同盟的免租、期限与敌对解盟共用关系状态。
6. 暂停保留待答内容；旧令牌、错误应答者、重复提交一律原子拒绝。结算后回到原行动或有明确债务/受限结果。

## States And Feedback

待使用、预览、反应待答、暂停、成功、目标无效、售罄/卡包满、状态到期、债务/破产与终局分别反馈。应答面板写明谁操作，不能用普通当前玩家按钮替代他人决定；原版自动消费若改为Web确认必须明确标注。

## Rules And Edge Cases

已确认梦游/陷害无反制直接他人5，自身重定向4，复仇回源5；免罪先于嫁祸；冬眠/停留/乌龟不套用未经证实的同一反制链。免费/租金嫁祸入口在租金≥2000（物价1）或总资金不足时检查。槽序按获取先后、消耗首个匹配；满包先替换首张最低价卡再收取/消费。同盟清双方旧关系、双向期限7；正向敌意解盟。旧版规则不得随新语义改变。

## Data And Technical Notes

先冻结v8实际1130命令回放及状态/事件SHA-256。新状态记录卡槽、关系、待处理反应与恢复位置，纳入独立规则/物品指纹。GameEngine保留行动玩家，反应命令单独校验应答者，所有流程确定性回放，不用墙钟超时。新语义只在v9启用；UI由session快照驱动。

3. Optional Enhancements：G4/G5后续触发点、完整日期/AI/特殊角色/原版音画与精确运行对照。
