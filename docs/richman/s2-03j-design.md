# S2-03j 设计约定

## Goal
补齐日本最后五槽2/3/4/6/7，新增v23；保留v1～v22回放与43物品、36新闻。

## Scope
冒贷、银行拒绝往来、挪用存款、强迫出国、外星人绑架。沿用日本基础场景、候选物价1和自身行动时钟。日历贷款到期、原强拍、完整保险不补猜测。

## Core Gameplay
正常走到命运地点依既有37槽序列抽取；立即结算财务或先处理旅行免罪/嫁祸。确认结果后继续轮转；旅行者暂离地图，到期从原路格返回。

## Screen Structure
复用命运结果、嫁祸侧栏、玩家状态与银行面板。显示冒贷本金、逐人银行转账、拒绝期限、旅行实际目标及期限。旅行期间角色与选中环隐藏，玩家列表保留状态。

## Interaction Flow
神仙判定 → 自动免罪（旅行）→ 可选嫁祸 → 实际目标结算 → 结果确认。银行拒绝期间可查看拒绝原因并离开，不能存取、借还款。错误玩家、旧token及暂停操作不生效。

## States And Feedback
v23独有可选字段：Mobility.travel原始字节；business.bankRejected按玩家记录。旅行低6位期限、bit6类型、bit7释放；入场清酒店/监禁/住院及名册，原路格/朝向/车辆保留。显示按行动计时，不写成原日历天数。

## Rules And Edge Cases
2增加10000贷款，不发钱、不当场收钱，+70取消或双倍；到期日明确未实现。3拒绝原值加30按byte溢出，+70取消，双倍码不加倍。4按座位其他未破产玩家银行余额×float32(0.1)向零截断，银行到银行，包含拘留/旅行者；无神仙、卡片反应。6/7基础3，+72取消或双倍，免罪优先于嫁祸且不递归；两模式无直接扣费，保险调用暂留。既有旅行低6位加新编码并byte截断；无新落点事件。

## Data And Technical Notes
独立final-fortune规则指纹接v22。新字段放既有g2/news世界树以被时光机保存；旧版本不初始化字段。detained/presence复用处纳入旅行，原拘留名册不混入旅行；银行命令与UI双重限制。固定ASM blob校验并登记来源。
