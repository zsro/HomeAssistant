# S2-02 第六批：首张可玩卡片——均贫卡

日期：2026-10-03。新增 `card:02` 均贫卡，完成点数获取→商店购买→持有→目标预览→取消/确认→现金结算→回收→再次购买/破产清理→回放。累计 **5/43 项可玩（1/30 卡片、4/13 道具）**，S2-02 整体仍未完成；[逐项清单](s2-02-progress.md) 保留 38 项缺口。

## 当前入口与规则

默认新场景为“卡片与道具对局（均贫卡）”，模式 `cards`，规则 `japan-tools-candidate-v5`，指纹 **`4df2b87b`**。继承 v4 路障、机器娃娃、邻近工人、遥控骰子与既有经济/财务；菜单保留所有旧模式。

开局卡片为 0。停在已有点数格攒点，在三越百货花费 **200 点**购买均贫卡，全局供应 **2 张**。卡片共用 **15 格**，不与道具数量混算；无库存或背包满不能买。购买仍停留商店，更新决策令牌；不能刚买完就越过回合阶段使用。

掷骰前，选择角色附近一位未破产对手。面板显示双方现金结算前后值，明确“存款不变”。确认消费 1 张，双方现金均设为 `floor((己方现金 + 对方现金) / 2)`，卡片返池；总额为奇数时丢弃 1 元，而不是把余数暗中发给某人。相等现金、己方更富及零现金都允许使用，界面提示消耗或让利。取消不扣卡；确认后仍可用其他道具/掷骰。无需对手二次同意，卡片效果即为强制平均。

## 显式差异与边界

- 目标范围：沿用固定方向 0、角色道路中心、440×440 锚点集合；列表可选，镜头无权扩大范围，不进行像素遮挡研究。属于 Web 候选，不声称与原版命中范围完全一致。住院/监狱/特殊角色尚无对应状态，不编造其卡片交互。
- 原版还更新仇恨和人物发言；本批没有 AI 仇恨和音频，未复制它们。当前只实现实际有意义的现金效果。
- 商店仅新增均贫卡；随机卡格、抽奖/开局随机发卡、卖卡和其他卡片尚未开放。15 格共用容量已接，但单一均贫卡池总计 2 张，真实 v5 游戏暂时不会占满 15 格；容量边界由纯规则/UI 测试覆盖。
- 金额用安全整数并避免先求大数和溢出；不会模拟参考 32 位整数溢出。卡片效果不触发租金/债务或落点结算；0 现金本身不等于破产。
- v4、v3、v2、v1 与更早 profile、指纹和处理语义保留。新增**修改前**真实 v4 回放及状态/事件 SHA-256 基准，确保此次改动后逐字节 JSON 哈希相同；回放容器仍 v1。
