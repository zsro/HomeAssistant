## 规则登记

固定参考提交 `ec7d70e693059d1e781d9d1cc2ad7f36d360d39e` 的买卖/均价/认股收付款、银行借还款与90日期限入口已重读，复用 S2-04a/b、S2-03o/k/v 的既有核验。没有新增 Windows 原版观测。下列数值与取舍属于 Web 策略，不声称原 AI 或投资最优解。详见[来源](s3-02m-sources.json)。

| 登记 | 实现与边界 |
|---|---|
| R10-01m 版本与归属 | 十三旧 policy 原样委托。非当前实际付款人/反应者/竞价者先委托 gods-v1，不按当前玩家预算卖股。只在既有合法窗口行动，暂停/重开/换局/退出使排队失效；恢复后重新计算行情、配额和预算。 |
| R10-02m 资金留存 | 经营缓冲为 `max(10000,5000+当前最大普通非己非盟连锁租金)`，再加持股公司当前负本期资金的绝对值总和；投资留存再加本金。负收益按整家公司损失保守预留，不冒充原分红按实际持股人分母计算的净账单。持仓成本上限为 `min(10000,floor((流动资金+成本-贷款)/5))`，下限0。仅当前公开风险，不涵盖未来所有设施费用、卡片支出或意外。 |
| R10-03m 普通买入 | 只首次建仓，不普通补仓；当前价≤目录初始报价90%、没有黑趋势/负公司资金/停牌/涨停，并满足交易日/市场/状态门控。每笔≤100股且≤5000元，银行留下全部缓冲，组合成本、现有pool/quota及盟友经营权同时限量；实付至少100元。初始报价只是固定启发锚点，不是内在价值或未来行情预测。 |
| R10-04m 普通卖出 | 当前可交易时，先按资金缺口向上取整卖必要股数；否则浮盈≥500元且当前价≥均价120%时卖出全仓，但保留自营公司的盈利仓。停牌/跌停不普通卖；实际付款时既有强制卖股仍由原调用者执行。清仓后可能按折价条件重新小额建仓一次，新均价消除旧盈利门槛，不产生原价无限买卖。 |
| R08-01m 账本复用 | 普通买卖只收付银行，金额按当前整元规则截断，更新普通供应/配额、float32均价与经营权；部分卖出保留均价，清零归零。卡片改价是未实现市值变化，不计为现金或公司收入。策略没有新增手续费、税或原精度算法。 |
| R10-05m 现场认股 | 只处理已合法到店开启的认股窗口。价格`trunc(公司资本/10000)`较现报价至少折价10%、无本金/负公司资金才认购；≤100股/5000元，现金保留5000，总流动资金保留预算，并重算待办上限与剩余认股份额。现金支付、认股池减少，普通pool/quota/报价和营业账本不变。既有规则允许休市/停牌时认股，不擅自套普通交易门控。 |
| R10-06m 同盟与经营权 | 若盟友正经营目标公司，最多买到与其持股相同，复用既有平手排名保留旧经营者。盈利清仓保留自己当前经营权；资金缺口卖股仍优先生存。不会为未持股公司的历史亏损预留现金，故未来取得经营权仍可能产生经营风险。 |
| R10-07m 银行/贷款 | 银行拒绝往来就离开；现金+银行高于经营缓冲时优先偿还本金，先银行后现金。剩余本金与到期日按现有规则保持/清除。仅无本金、无持股市值、有地且额度足够覆盖整个缺口时，将流动资金补至5000；不追加/展期借款，不借款投资。随后存取款把现金调至`min(5000,流动资金)`，完成即离开。 |
| R05-01m 日期与费用 | 复用首次借款90日、原交易日顺延、部分还款不延期、还清清日期；有本金停每月存款息，不添加贷款复利。到期催收/必要清股/退出依现有付款flags与回调执行。没有读取未来命运冒贷、隐藏日期事件或预抽行情。 |
| R10-08m 购建/反应 | 可选购地/升级后现金不足3000或流动资金不足投资留存时放弃；必须支付的租金继续原接口。免费/嫁祸先结算，确认实际付款人后才必要清股；公共处置收入既不救活退出者，也不代付原债。旧主动卡片/研究等优先级保留，预算不是所有旧卡片支出的全局拦截。 |
| R10-09m 信息边界 | 读取公开余额、本金、持股/均价、报价/配额/停牌、公司资金/资本/经营权、同盟、产权、合法待办。无隐藏新闻/命运序列、种子、随机状态或 G7 快照访问，不消耗游戏RNG进行决策。 |

## 未覆盖与差异

没有把这批短中程路线说成新完整终局。浏览器未穷举部分还款/现金补付、全部停牌/跌停/节假日/经营负债/同盟平手、瞬时配额失效以及新policy嫁祸租金后公共强拍；对应已测领域/历史与未测UI分别登记。旧43项物品/36条新闻/日本37槽命运保持，不重算为本轮重新验收。

此策略不预测行情，不保证不亏损或永不破产。低于开局价也可能继续下跌；公司未来费用与长期陷阱、全部设施连锁没有预算保证。借贷会损失月息资格且有90日到期风险；只做低额应急，不新增套利/循环融资。原AI权重、原行情精度/RNG/走势图、其他资产挂牌、特殊角色、原转盘、原退出调用栈/终局和小游戏表现/碰撞差异保留。
