# G4 设计 / v10

## Goal
一次接入改建、拍卖、查税、涨价、查封五卡及必要建筑基础；目标29/43已实现，验收保持18/43。

## Scope
包含五卡合法购买/库存/选择/取消/消费、普通与大型用地、建筑种类、独立竞价人、查税反应、价格状态和回放。原版转盘音画、AI、科研道具生产与完整S2-03另行接续。所有自动测试等待43项实现后统一执行。

## Core Gameplay
攒点→三越百货购买→掷骰前用卡→预览目标和变化→确认→完成反应或竞价→继续本回合。地产购买/建造与租金继续由落点触发；破产和胜负沿用现有流程。

## Screen Structure
原地图保留；侧栏新增G4库存、改建类型选择、多人竞价与查税应答。地产列表与地图标签显示种类及涨价/查封期限。

## Interaction Flow
选卡后先预览；取消不消费。拍卖确认后消耗卡并进入不可撤销的依次竞价，标明竞价人、现金、出价与退出。查税先免费，再满足阈值时嫁祸，最后显示实际付款者与收款者。

## States And Feedback
无目标/无卡/无点数禁用；独立决策令牌拒绝旧选择/重复提交/错人。暂停锁定侧栏且所有计时静止；重开清空建筑状态/竞价/反应。失败保留当前有效决策并显示原因。

## Rules And Edge Cases
查税取现金20%向零取整，转移后重算；普通街区价格状态覆盖而非叠加；5个全局轮次为Web日期替代。改建普通住宅与连锁店互换，变店封顶1级；大型类型0/3封顶1级，其余5级。拍卖当前地块，标价为地价×(1+0.5×级数)，发起者不竞价，现金不足/行动受限者不参加；无人竞价恢复待售。

## Data And Technical Notes
新g4/v10独立指纹，旧v1–v9保持可选。G4模块处理五卡与拍卖/查税；地产扩展字段只在v10初始化。沿用v9有序卡包/库存/资金/同盟。所有新决策写入命令与事件，不用墙钟或浏览器随机数。

## Delivery Slices
1. MVP：整组规则与可玩UI、建筑基础、版本隔离和真实状态登记。
2. Polish：43项完成后集中自动测试/浏览器验证；修正实际问题。
3. Optional Enhancements：Windows运行对照、专用建筑动画、科研生产与其他S2-03内容。
