# S2-02 第六批：均贫卡

## Goal
新增首张可玩的卡片：通过已有点数经济在三越百货购买均贫卡，再选择对手平均双方现金，完成库存、供应、消费、回放闭环。
## Scope
纳入独立 v5、均贫卡 200 点/有限池 2 张、卡片总容量 15、合法目标/预览/取消、破产库存回收。保留 v4 及全部旧版本。暂不开放随机抽卡、满背包随机获取替换、卖卡、其他 29 卡及仇恨/AI；这些不能假称已实现。
## Core Gameplay
落点获得点数 → 商店花费 200 点获得卡 → 下一次掷骰前选择附近存活对手 → 预览双方现金与取整 → 确认各设为平均数，卡片返池 → 继续使用道具/掷骰。取消不消费；胜负仍沿用既有财务规则。
## Screen Structure
我的卡片显示均贫卡数量、获取说明和背包占用；商店显示单价、剩余供应、禁用原因；选择面板展示对手角色名、两人的现金前后值、存款不变和奇数损耗；旅途记录显示结算。
## Interaction Flow
1. 开局卡片为 0，规则不额外赠送。2. 满足 200 点且有供应、背包未满时购买，刷新商店决策令牌。3. 掷骰前使用，选择一个候选对手。4. 确认/取消；确认时引擎重新核验身份、目标、库存和现金计算。5. 成功后仍可掷骰，重开恢复空背包及两张供应。
## States And Feedback
无卡、无附近目标、库存售罄、点数不足、背包已满均显示原因。暂停禁用购买/选择/确认/取消。相等现金或向对手让利允许使用，但明确显示仍会消耗。窄屏、全屏保持同一选择和预览。
## Rules And Edge Cases
参考只平均双方现金，以非负整数向下取整，奇数总额损失 1；存款/地产/点数/RNG/位置均不改。卡片 15 格与道具分开计数；商店满背包拒购，区别于原版随机发卡时淘汰最便宜卡。破产返卡池但沿用既有不折现清算。未开放满池随机抽取，不能只在已实现的一张卡中伪造原版抽卡。
