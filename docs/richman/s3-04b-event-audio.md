## 调度与生命周期

表现版本为 **event-audio-v1**，游戏规则仍v47。

- 复用原音乐通道，另分音效与语音通道，可同时播放。语音播放时音乐降为所选音量的35%，结束/取消后恢复；增加独立语音音量，旧音量偏好自动补默认80%。这是Web混音约定，不是原音量曲线复刻。
- 每通道最多1条在播、3条等待。普通地点/点数优先级1，购建/满级语音优先级2；同级按序等待，高级打断低级并清旧积压，队列溢出丢弃低优先级/较新的尾项。原说话入口是替换UI语音缓冲，Web队列与原弹窗阻塞时序明确不同。
- 局号/revision/事件序号去重；同一事件可以分别发音效和语音，同通道同片段重复不重播。锁定、音量零、静音、隐藏、暂停、回放及终局期间的提示丢弃，不在恢复时补播。
- 下一行动、道具取消、时光机实际消耗、重开/换局和退出清在播短音与等待队列。时光机不恢复声音世界，也不倒退音频事件游标。晚到的`play`返回、失败或`ended`回调不能复活旧局/旧队列。
- 保留首次点击开启及播放失败后的显式重试。缺少新扩展的旧音频清单仍可播放基础音乐/音效；扩展清单若声明本版本却缺失文件映射会拒绝。媒体播放失败只影响声音，游戏可以继续。

无新增等待游戏命令，声音不阻塞规则推进。Session只在新局或接受命令后发送脱离状态对象的声音数据；插值帧不重复复制世界。队列属于页面生命周期，没有写入规则状态、RNG或任何回放。
