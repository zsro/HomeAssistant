# S2-02 第七批：均富卡多人现金平均

日期：2026-10-03。新增 `card:01` 均富卡，复用商店、卡片库存和消费协议。累计 **6/43 项可玩（2/30 卡片、4/13 道具），37 项未开放**；S2-02 整体仍未完成。设计见 [本批设计](s2-02g-design.md)，逐项范围见 [43 项进度](s2-02-progress.md)。

## 入口与玩法

新场景默认 `wealth` / `japan-tools-candidate-v6`，指纹 `410bc234`，菜单为“卡片与道具对局（均富卡＋均贫卡）”。保留 `cards` v5 及所有旧模式。

初始均富卡 0 张，在三越百货花费 **200 点**购买，**全局供应 1 张**。与均贫卡共用 15 格卡片容量，各自供应池独立。掷骰前使用，预览列出包括使用者在内的全部未破产玩家及现金变化；不选择对手、不检查距离。确认消费 1 张，每人现金变为 `floor(参与者现金总和 / 参与人数)`，余数舍弃；取消不消费。存款、地产、点数、位置、回合和 RNG 不变；仍可使用其他卡/道具或掷骰。使用后返池，可再次购买；破产持有者的未用卡也返池。
