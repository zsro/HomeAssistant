# S2-03i 交通与地区命运设计

## Goal
在原日本地图新增交通与地区命运闭环，保留v21及所有旧回放。

## Scope
纳入10～16与日本地区41～44（槽33～36）共11项，累计32/37槽；不新增日期、保险公司、其他地区或原破产强拍。

## Core Gameplay
落点命运轮选 → 按交通方式改派 → 神仙修正 → 即时车辆/罚款结算，或免罪/嫁祸 → 住院/监禁 → 结果确认 → 继续原行动顺序。

## Screen Structure
复用命运结果和反应侧栏。显示命运名称、实际目标、期限、车辆及资金变化；嫁祸窗口明确显示住院或监禁和实际期限，不冒用卡片陷害的4/5期限。

## Interaction Flow
先判神仙取消或加倍。拘留类自动优先消耗免罪，否则有嫁祸时可选任何其他在局玩家或放弃；只处理一次反应，不递归、不复仇、不破坏同盟。完成后独立确认token，不重复结算。暂停禁止应答，重开取消保留状态。

## States And Feedback
决策中保持原活动玩家；反应明确未结算。实际目标强制移到医院/监狱，无地点再触发；结果展示原/新期限。丢车恢复步行1骰，原包内车辆不丢失。

## Rules And Edge Cases
10/11仅机车/汽车可入选并互相改派；12/13仅步行/机车并按当前方式改派；14～16按步行/机车/汽车改派，工程车跳过。住院3，地区41～44为3/5/7/9，+72神仙取消或双倍；罚款3000使用+70神仙修正，先现金后存款、实收进公共资金，不卖股救罚款。住院目标在外时损毁当前车返池，已在设施/住宿者保留；监禁不毁车。复用候选行动计时与设施名单，明确原日历及保险补偿缺口。

## Data And Technical Notes
独立v22和指纹；结果记录源槽、改派id、实际目标和前后状态。新反应continuation不改旧规则；命运游标/状态纳入既有时光机快照，随机数不倒退。默认交通命运模式，保留旧入口。

## Delivery Slices
1. MVP：固定证据、改派、车辆/资金/拘留及反应接线。
2. Polish：边界测试、原图合法获取路线、正常速度浏览器/回放、结果与接续记录。
3. Optional Enhancements：日期/保险与原版表现留后续专项，不纳入本批通过范围。
