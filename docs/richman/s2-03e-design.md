# S2-03e 设计：拘留与交通新闻

## Goal
沿固定来源接入新闻0～3与16/17，共六条，使释放、延长和交通停留在现有对局中可见、可操作、可回放。

## Scope
In scope：v18、独立设施名单、现有状态时钟及车辆分类、新闻面板与实际路线。Out of scope：原版日期、结息、破产强拍、像素遮挡和新素材。

## Core Gameplay
合法移动到新闻格，序列选中合格新闻，自动结算名单内全体玩家并展示前后状态；确认结束回合，到目标行动时推进期限。重开清状态，回放复现。

## Screen Structure
保留画布、玩家状态栏、新闻变化明细、继续回合与暂停/全屏。设置新增十八版模式并保留旧版。

## Interaction Flow
1. 卡片陷害、道路攻击、车辆补购等既有机制建立条件。
2. 新闻展示释放标志、延长三次或停留一次，标明下次行动处理。
3. 确认后按原流程轮换，不再执行本次落点，不重复结算。

## States And Feedback
新闻已结算但未确认、暂停禁止确认、失效token提示、无合格对象跳过。设施释放先标记128且清名单；状态栏保留“下次解除”。交通停留写1，叠加其他限制时可能在拘留期间计时消耗，明确提示。

## Rules And Edge Cases
0/2清设施名单与写128；1/3仅名单中者(raw+3)&127，保留原7位边界。自然计时128仍在名单，可加刑；新闻释放128已出名单，不再加刑。16/17包含所有未退出者，不排除拘留、冬眠、梦游和住宿；按当前车辆而非背包/保存车辆分类，工程车算车辆、梦游暂停工程车算步行。只覆盖停留，不改骰数、乌龟或其他状态；不触发卡片反应。

## Data And Technical Notes
仅v18 NewsState增加prison/hospital名单；统一入院/入狱函数、自然释放与破产同步。时光机既有news快照一并恢复名单。事件记录目标集合及mobility前后值。v17以下不添加字段、不改指纹。

## Delivery Slices
1. MVP：证据、名单与六条规则，领域边界测试。
2. Polish：合法原图浏览器路线、独立回放核验、截图与接续卡。
3. Optional Enhancements：原版日期/表现和余下新闻由后续批次核验。
