# S3-02i：主动范围建拆策略

新增宿主 `area-v1`，继承 `commerce-v1`，保留九个旧policy。世界规则保持 `japan-events-candidate-v44 / f9dbb7e9`。本批只增加电脑决策，没有重做卡片效果。四条原图正常速度浏览器及独立建拆结算、关键前缀/完整回放通过；2169项测试分两次通过，lint/build与十种策略打包UI通过。

## 依据与策略

沿[G5核验](s2-02l-g5.md)、[43项统一验收](s2-02o-unified.md)及[经营策略](s3-02h-commerce-strategy.md)。本批重读固定提交三卡汇编，SHA-256与G5登记一致。原入口天使按同名遍历加盖，恶魔按同名清空楼级和类型，怪兽经mode2单地拆除；消费、敌对与原AI入口可见。策略是自定义静态启发式，未声称还原原版AI/难度或Windows实机一致。

| 卡片 | area-v1取舍 | 沿用v44效果 |
| --- | --- | --- |
| 天使09 | 检查整组实际会改变的地产，拒绝为敌方或待售地加盖；允许盟友同时受益，但必须有自有净收益。满级/满级连锁无变化不计收益。自有空大型地显式选购物中心2；已有建筑不换类型 | 普通同名街区或单块大型地加一级，各自受类型上限约束；产权/现金不变，满级仍可由人类使用并耗卡 |
| 恶魔10 | 整组不得拆掉自己或盟友建筑/类型/科研任务；必须有敌方当前建筑投资或静态租金损失。未持有建筑可被连带拆除，但不计收益 | 普通同名整街或单大型地清零楼级/类型/科研，保留产权和价格状态 |
| 怪兽11 | 仅从原合法非己方、有楼单块目标中选取；避开盟友，敌方当前损失为正 | 只清空所选单块，同行其他地块保留；清科研、保留产权/价格状态 |

评分为**受益方当前楼级差×基础建造价，加同业主全部地产静态租金变化**。天使只把自己的变化计入分值；恶魔/怪兽只计敌方。静态租金复用commerceRent：普通同名住宅/同业主连锁聚合，饭店/购物取单份费用；封地为0、涨价倍率2。分值只用于同一时点排序，不表示实收、出售价格、未来收益或股权资产；没有给科研产品虚拟收入，不抽转盘、不运行引擎预测未来。当前统一物价不改变候选相对排序，不重复缩放字段。固定卡序09/10/11、再按地产id打破平分。

原实际作用集合始终保持，不能把“整条街”过滤成只改自己/敌人。天使提升有效研究所保留项目与剩余期限，不提前生产；拆毁研究所清项目。盟友科研受保护，不因临时查封就忽略所有权风险。尚未有建筑但类型会被拆除重置的自有/盟友地也会阻止整街攻击。满级敌方/待售地不发生升级时不会阻止天使帮助自己。

确认重新计算合法范围、库存、类型和全组收益；全部候选失效则取消、不消费。出现另一安全候选可重新选它。源被原规则禁止行动时不发非法确认/取消。效果成功消费一张、原有限池返还一张、保持idle/行动者/日期/RNG，继续可用卡或掷骰。三卡不触发免罪/嫁祸/复仇；拆除沿旧敌意，不增加新反应窗口。费用仅获取时的点数，不虚构使用现金费或保险赔款。

商店按原货架、供应、15槽和点数，空库存各补一张160/180/60点；已有库存不重复囤积。正常魔法/地图/神仙/抢夺获取同样可用。无新开局赠卡。没有有效新动作则委托commerce-v1；非当前反应/竞价应答者同样委托其已有策略。policy只在Session及回放control，不进入世界GameConfig/指纹。不读隐藏新闻/命运/seed/RNG/G7快照，不消耗游戏随机数。
