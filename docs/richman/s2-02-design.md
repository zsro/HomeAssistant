# S2-02 首个道具闭环设计

## Goal
让玩家在正常日本地图对局中使用遥控骰子、获得点数并在三越百货补购，完成可回放闭环。
## Scope
本轮仅开放遥控骰子、独立点数账户、原地图点数落点、商店购买。转向卡目标掩码/路口方向仍不明确，延期；其他物品、随机发卡、售卖、车辆、神仙不开放。
## Core Gameplay
候选开局每人 1 个遥控骰子（共享供应 10 减去人数）、0 点数 → 掷骰前选择道具 → 选择 1–6 或取消 → 确认扣一个并出发 → 落点奖励点数 → 商店以 30 点购买 → 后续回合再次使用。
## Screen Structure
新建模式加入“道具对局”，成为新场景默认；原地产模式保留。侧栏显示当前玩家点数、数量、使用按钮；选择时显示六个点数与确认/取消。商店显示单价、共享余量、持有上限 9 和离开按钮；四人面板显示各自点数。
## Interaction Flow
使用前校验当前人/版本/阶段 → 内核创建选择 token → 确认校验 1–6、自身目标与库存 → 原子提交消耗、供应回补和滚动动画 → 走原有移动/银行/地产流程。取消回到待掷骰；选择中禁止普通掷骰和结束回合。
## States And Feedback
无道具禁用使用；非待掷骰阶段禁用。点数不足、供应空、已持有 9 个禁用购买。暂停冻结操作，重开恢复配置/初始库存/点数，旧 token 无效。终局不再开放道具或购买。
## Rules And Edge Cases
点数格仅落点触发；商店节点 50/107 共用公司 1 和供应池。成功购买更新 token 防双击。指定骰子不推进随机状态；普通骰子延用原 RNG。破产回收道具供应并清理库存/点数，不把道具折算现金抵债。点数用非负安全整数；不模拟原 16 位溢出。
## Data And Technical Notes
新 profile `japan-tools-candidate-v1`，使用现有 effects 内核。状态/回放容器仍 v1，仅新 profile 增加 items/effects 与规则指纹；旧三个 profile 保留。节点绑定从既有原地图审计生成小目录，不修改地图/素材清单。领域提交只由 GameEngine 完成；UI 不修改库存。所有数值语义仍是跨版本候选。
## Delivery Slices
MVP：遥控骰子、奖励点数、商店补购和回放。Polish：暂停/取消/重开/全屏/窄屏与完整对局回归。后续：S2-02 继续分批卡片和道具，S2-03 扩展其他事件，S2-04 股票。
